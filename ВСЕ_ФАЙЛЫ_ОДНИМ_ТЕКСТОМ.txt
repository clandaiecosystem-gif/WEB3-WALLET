# SmartWalletGuard v6.1.0 — что сделано по новому ТЗ

Обновление поверх рабочей разбивки v6.0.0. Монолит не возвращался: Guard,
OwnerRegistry, PolicyRegistry, SubscriptionManager остались отдельными, плюс
добавлены MigrationHub и MigrationModule.

## 1. Итог компиляции (solc 0.8.30, optimizer 200, viaIR, 0 errors)

```text

SmartWalletGuard                        23459      24420   ok
SmartWalletPolicyRegistry               21861      22229   ok
SmartWalletGuardSubscriptions           22500      23663   ok
SmartWalletGuardMigrationModule         13791      14421   ok
SmartWalletMigrationHub                  7086       7625   ok
SmartWalletGuardOwnerRegistry            5760       5928   ok
GuardOps (library)                         57         85
```

## 2. Adapter architecture удалена

Удалено полностью, а не «доработано»:

| Удалено | Где было |
|---|---|
| `ISwapAdapterView` | GuardInterfaces, Guard |
| `AdapterPolicy`, `adapterPolicy`, `getAdapterPolicy` | PolicyRegistry |
| `addAdapter`, `removeAdapter`, `increaseAdapterLimit`, `changeAdapterDeadline` | PolicyRegistry, Subscriptions |
| `spendAdapter`, `consumeWhitelist` | PolicyRegistry |
| `executeSwap` | Guard |
| проверки `adapter.guard()`, `adapter.code.length` | Guard |
| передача токенов сначала адаптеру | Guard |
| `AdapterBlacklisted/WrongGuard/NotRegistered/LimitExceeded/DeadlineExpired` | Guard, PolicyRegistry |
| `adapterEntries` в миграции | MigrationHub |

Вместо этого один универсальный путь: Guard знает только
`targetContract + token + amount` и не знает, что этот контракт делает.
Никаких `UniswapAdapter` / `CurveAdapter` / `AaveAdapter` больше нет.

## 3. Whitelist заменён на contract-level policy

`whitelist[recipient][token]` больше не существует.

```solidity
struct ContractPolicy {
    bool exists;
    bool blocked;            // §19: полная блокировка контракта
    uint256 usdLimit;        // микро-USD (1e6 = $1); 0 => автотрата запрещена (§15)
    uint256 usdSpent;        // §16, §17
    uint256 maxTokenShareBps;// 2000 = 20 % (§6, §10)
    uint256 deadline;        // §20
}
mapping(address => ContractPolicy) public contractPolicy;   // ключ = smart contract
```

Одна запись на **контракт**, а не на «контракт + токен». `recipient` и `spender`
больше не смешиваются: `executeOnContract` расходует в пользу `targetContract`,
`transfer`/`transferNative` переводят на адрес получателя.

## 4. Категория риска токена (§5-§9)

```solidity
enum TokenRiskCategory { GREEN, YELLOW, RED }
mapping(address => TokenRisk) private _tokenRisk;   // configured + category
function effectiveTokenRisk(address) returns (TokenRiskCategory); // UNKNOWN => RED
```

* **GREEN** — есть заранее настроенная цена: USD-лимит **+** доля баланса.
* **YELLOW** — `TokenAmountPolicy` (абсолютное количество) **+** доля баланса.
* **RED** — то же, что YELLOW.
* **UNKNOWN** — по умолчанию RED (`effectiveTokenRisk` возвращает RED, если
  токен не сконфигурирован). Нельзя получить «неизвестный токен + поддельная
  цена + $1000 лимит = весь supply»: без записи в registry USD-режим не
  включается, а без `TokenAmountPolicy` операция отклоняется вовсе.

## 5. Защита от исчерпания supply (§10, §11)

Доля баланса считается on-chain по `IERC20(token).balanceOf(wallet)` и
применяется **всегда** — и для GREEN, и для YELLOW, и для RED, и для обычных
переводов на адрес получателя (`defaultTransferShareBps`). Баланс берётся
**до** операции, поэтому дробление вывода на много транзакций не помогает.
Backend не передаёт баланс как trusted input — он в подписи вообще не участвует.

## 6. Approve (§12, §13, §14)

`guard.approveOnContract(...)`:

* `type(uint256).max` → `UnlimitedApprove` (§13);
* approve на конкретную сумму проходит через ту же `checkAndSpend`, поэтому
  увеличивает `usdSpent`;
* множество approve не обходит лимит: второй approve на ту же сумму упирается
  в исчерпанный `usdLimit` (тест `MultipleApprovalsCannotBypassPolicy`).

## 7. Limit = 0 и strict-режим (§15, §52)

`usdLimit == 0` означает «автотрата запрещена»: операция требует
дополнительной подписи локального security-ключа. Ключ задаётся через
`strictKey` / `pendingStrictKey` (propose → accept, как rotation в ТЗ v5.1.4
§36), разблокируется на устройстве паролем; on-chain хранится только адрес.
Флаг `strict` входит в EIP-712 digest, поэтому обычную подпись нельзя
переиспользовать как strict-операцию.

## 8. Migration: MigrationHub — единственный источник истины (§28-§34)

Guard больше **не хранит** `migratedOut`, `migrationAccepted`, `migratedTo` и
не имеет `markMigratedOut` / `acceptMigrationIn`. Guard читает состояние у Hub:

```solidity
modifier notMigrated() {
    if (msg.sender != hub) {
        if (IMigrationHubView(migrationHub).finalizedOut(address(this))) revert MigratedOutError();
        if (expectedOldGuard != address(0)
            && !IMigrationHubView(migrationHub).acceptedFrom(address(this), expectedOldGuard))
            revert MigrationNotAccepted();
    }
    _;
}
```

Hub ведёт `MigrationState { NONE, PROPOSED, READY, FINALIZED, CANCELLED }`,
`Migration { oldGuard, newGuard, migrationDataHash, proposedAt, executableAt,
state, emergency }`, `currentMigrationId`, `acceptedFrom`, `finalizedOut`,
`migrationCancelCount`. Старый Guard не «передаёт state» новому — Hub знает
обоих.

Сохранено: 48 h, `MAX_MIGRATION_CANCELS = 3`, emergency-путь только после трёх
отмен и с подписью `migrationEmergencyKey` + 3/5 + Cold. Исправлен дефект
v5.2.1/v6.0.0: `executeAfter` входит в digest как подписанное значение, а не как
`block.timestamp` после подписи.

Применение снапшота выполняет `SmartWalletGuardMigrationModule`: Hub только
ведёт состояние и таймлок, модуль проверяет `authorizedMigration(newGuard)`,
 `acceptedFrom(newGuard, oldGuard)` и сверяет каждый элемент снапшота со старым
Guard-ом/Registry.

## 9. Что сохранено без изменений (как просили)

* **OwnerRegistry / EIP-712** — thresholds 2/3 Hot и 3/5 + Cold не менялись.
* **Permit2 expiration** — `expiration != 0 && expiration >= block.timestamp`.
* **Emergency Sweep** — 2/3 Hot, без Cold, без подписки, без whitelist/policy,
  получатель только из `recoveryTargets` (тесты 30-33).
* **Подписка** — on-chain, FREE / STANDARD / PREMIUM, истёкшая подписка
  отключает платные функции, но не emergency (тесты 34-38).

### 11.1 Найдено и исправлено после первого прохода

При подготовке выгрузки я проверил итоговые файлы перебором и нашёл **недодел**:

# SmartWalletGuard: аудит, исправления и архитектурная переработка

Проверены: ТЗ `SmartWalletGuard v5.1.4.docx` (извлечён в `spec-v5.1.4.txt`),
монолитный `SmartWalletGuardCore-v5.2.1.sol`, `SmartWalletService-v1.0.1.sol`,

## 1. Главное: контракт v5.2.1 невозможно развернуть

уточнением: проверить это раньше не могли, потому что **компилятор не запускался**.
Я скачал `soljson-v0.8.30` и запустил реальный solc.

## 2. Что ещё проверено в поставке

### 2.1 Тестовый файл `SmartWalletService.t.sol` в текущем виде не является валидным Foundry-тестом

```solidity
interface Vm {
    function expectRevert(bytes calldata) external;   // у Foundry возвращает Vm
}
vm.expectRevert(bytes("plan disabled"));              // компилятор обязан ругаться
```

`vm.expectRevert` в Foundry объявлен как `returns (Vm)`. Объявление в тестовом
файле не соответствует реальному интерфейсу, поэтому либо файл не компилируется
против настоящего `Vm`, либо тест не работает. Дополнительно: все проверки
сделаны через `require(...)`, то есть падение теста возможно только через
revert.

### 2.2 «Service» владел авторизацией Guard-а — это критическая ошибка модели

В v5.2.1 Guard спрашивал разрешения у внешнего контракта (`service`):

```solidity
require(ICoreService(currentService).hasPermission(mainWallet, permission), "subscription permission required");
```

`service` — обычный state, устанавливаемый 3/5 + Cold. Пока `service` не
установлен, `transfer`, `transferNative`, `executeSwap` **не работают вообще**
(«service not set»). Как только установлен — весь subscription-gate делегирован
внешнему контракту, который Guard не контролирует: контракт-клон с
`hasPermission() == true` открывает кошелёк. Это нарушает ТЗ §42 («подписка
хранится в Guard»), §79 («подписка не должна управлять custody») и §100
(«execution function должна проверять entitlement сама»).

### 2.3 Подписка записывалась до оплаты

```solidity
subscriptions[mainWallet] = Subscription(plan, uint64(nextExpiry));
core.collectSubscriptionPayment(uint8(plan), fromWallet, nonce, deadline, signatures);
```

В той же транзакции — но при revert оплаты откатывается и запись. Реальная
проблема не в атомарности, а в том, что **цены и включённость тарифа живут в
Service, а исполнение платежа — в Core**: расхождение состояния и оплаты
разнесено по двум контрактам, а `Core.collectSubscriptionPayment` требует
собственные подписи владельцев и собственный nonce-скоуп, поэтому платёж и
подписка не образуют одного проверяемого действия.

### 2.4 `proposeMigrationWithEmergency` практически неработоспособен

```solidity
uint256 executeAfter = block.timestamp;
bytes32 digest = ...(MIGRATION_EMERGENCY_TYPEHASH, ..., nonce, executeAfter, deadline);
require(_recover(digest, emergencySignature) == migrationEmergencyKey, "invalid emergency key");
```

`block.timestamp` входит в подписываемый digest, а `executeAfter` берётся из
него же. Подпись emergency-ключа валидна только в том блоке, в котором она была
создана: офлайн-подпись не проходит. Это же повторено в Service. Emergency-путь
(ТЗ §62/§63, Invariant 17) фактически недоступен.

### 2.5 Двойная регистрация платформ/роутеров

`Core` проверял `approvedRouter[router]`, а `Service` — собственный
`approvedTradingPlatform[router]`. Swap проходит только если контракт разрешён
**в обоих** реестрах, а обновлять их нужно двумя разными наборами подписей.
Любое расхождение = swap невозможен, при этом ТЗ §52 требует один реестр в Guard.

### 2.6 Отсутствуют данные для TZ-требования §96 (state enumerability)

Монолитный Core не хранил никаких списков: `hotWallets`, `coldWallets`,
`approvedToken`, `approvedRouter`, `blacklist`, `whitelist`, `adapterPolicy`,
`recoveryTargets` — голые mapping-и. `acceptMigration` принимает элементы
снапшота и проверяет каждый по отдельности, но **проверить полноту** (что
переданы все записи) невозможно: старый контракт не отдаёт списки. ТЗ §96
требует tracked lists именно для этого.

### 2.7 Прочие дефекты v5.2.1

| Дефект | Где | Последствие |
|---|---|---|
| `changeOwners` допускал дубликаты в `newOwners` в `changeOwners` | Core | проверка только `newOwners[j] != newOwners[i]` — на самом деле есть; в `acceptMigration` тоже есть. Снято с учёта после проверки. |
| `removeToken` не снимает whitelist-записи этого токена | Core | записи остаются «мёртвыми», но `transfer`/`swap` их отклоняют — поведение корректное, риск только в миграционном шуме. |
| Whitelist-операции без `nonReentrant` | Core | внешних вызовов нет, поэтому безопасно. |
| `_checkPermit2Allowance` без явного `exp != 0` | Core | требует ТЗ §41 / FIX 1; на практике совпадает, но формально нарушено. |
| Строковые revert-причины на 45 КБ | Core | ~4-5 КБ лишнего кода; при лимите EIP-170 это прямое ограничение. |

|---|---|
| `SmartWalletGuard` | авторизация и исполнение: transfer, native transfer, swap, emergency sweep, recovery target, owner rotation, wallet registry, migration hooks |
| `SmartWalletGuardOwnerRegistry` | владельцы 3 Hot / 2 Cold, проверка подписей, thresholds, Cold-требование, nonce, реестр Smart Wallet |
| `SmartWalletPolicyRegistry` | whitelist, adapter policies, blacklist, approved tokens/routers/trading platforms, recovery targets + enumerable-списки для миграции |
| `SmartWalletGuardSubscriptions` | подписка, plan configs, treasury, appVersionHash, P2P-конфиг, policy-вызовы с подписями |
| `GuardOps` | общий EIP-712 кодек (домен, структурные хеши, recover) |
| `GuardInterfaces` | общие интерфейсы без реализаций (разрывает циклические импорты) |

`SmartWalletGuard` — 23 629 байт при лимите 24 576, запас 947 байт;
`SmartWalletGuardSubscriptions` — 22 456 байт, запас 2 120 байт. Это осознанное
следствие того, что Guard обязан остаться единственным контрактом, который
двигает средства через Permit2: вынести исполнение означало бы второго
спендера Permit2 и отдельное разрешение от каждого кошелька. Любое добавление
кода в эти два контракта требует сначала что-то вынести.

Привязки не принимаются на веру и проверяются обеими сторонами:

* `SmartWalletGuard.constructor` → `ownerRegistry.guard() == address(this)`;
* `OwnerRegistry.setGuard` → вызывающий обязан ссылаться на этот OwnerRegistry;
* `Guard.configureModules` → `policyRegistry.isBoundTo(address(this))` и
  `subscriptions.isBoundTo(address(this))`; поэтому функция безопасна для
  любого вызывающего и не даёт подсунуть чужой контракт.

### 3.1 Исправленные ошибки

1. **Deployability.** 45 498 → 23 629 байт у основного контракта; все четыре
   deployable-контракта ниже лимита EIP-170, initcode — с большим запасом до
   49 152.
2. **Entitlement перенесён внутрь системы.** Убрана зависимость от внешнего
   «Service». Подписка и permission mask считаются в
   `SmartWalletGuardSubscriptions`, созданном той же системой и жёстко
   привязанном к Guard-у. Никакой контракт со стороны больше не может выдать
   права. (ТЗ §42, §79, §100, §108.)
3. **Атомарная подписка.** `subscribe` теперь одно действие:
   проверки → consumed nonce → подписи 2/3 Hot → проверка Permit2 allowance →
   `Permit2.transferFrom(wallet → treasury)` → запись плана. Нет окна
   «план записан, оплата не прошла».
4. **Permit2 expiration.** `expiration == 0` трактуется как истёкший allowance,
   требуется `expiration >= block.timestamp` (ТЗ §41, FIX 1).
5. **Emergency sweep независим от подписки и реестров.** Не проверяет
   `PERM_*`, не требует `approvedToken`, не требует whitelist; получатель
   берётся только из `recoveryTargets[wallet][token]`, blacklist получателя
   проверяется повторно в момент исполнения (ТЗ §32/§33/§58/§78, FIX 5, FIX 6,
   Invariant 7/8/9).
6. **Swap требует ровно один реестр роутеров и один реестр платформ**
   (`SmartWalletPolicyRegistry`): двойной контроль v5.2.1 снят, расхождение
   состояний невозможно.
7. **Whitelist получателя при swap применяется атомарно к фактическому
   результату.** `PolicyRegistry.consumeWhitelist` проверяет и списывает в
   одном вызове, поэтому favorable slippage не может превысить лимит
   (ТЗ §25).
8. **Enumerable-состояние для миграции.** Все миграционно-значимые множества
   имеют tracked-списки: `getBlacklist`, `getApprovedTokens`,
   `getApprovedRouters`, `getTradingPlatforms`, `getWhitelistKeys`,
   `getAdapterKeys`, `getRecoveryKeys` (ТЗ §96).
9. **Custom errors вместо строк** — во всех контрактах v6.
10. **Все подписи через один кодек.** `GuardOps` фиксирует
    `verifyingContract == address(this)`, поэтому подпись нельзя перенести на
    другой Guard или другую сеть (ТЗ §89). `PolicyOp` различает операции по
    `kind`/`op`, коллизии между разными операциями невозможны.
11. **Разделены шаги инициализации:** `configureModules` (permissionless, но
    адреса валидируются обратной привязкой) и `initializeOwners` (только hub).
    Установить произвольный состав владельцев нельзя даже фронтраннингом.

### 3.2 Сохранённое поведение ТЗ

Проверено по пунктам: 5 владельцев (3 Hot / 2 Cold), thresholds 2/3 и 3/5+Cold,
nonce-скоупы (hot wallet для исполнения, mainWallet для governance),
deadline во всех подписываемых операциях, whitelist/blacklist/registry
проверки в момент исполнения, migration 48 h + максимум 3 отмены,
подписка привязана к `mainWallet`, `block.timestamp >= expiresAt` = expired,
renewal того же тарифа от текущего expiry, смена тарифа от now.

## 4. Честные ограничения и что осталось

1. **`SmartWalletMigrationHub` не включён в поставку.** Guard отдаёт весь
   необходимый интерфейс миграции (`setHub`, `markMigratedOut`,
   `acceptMigrationIn`, `claimOwners`, `claimWallet`, `claimSubscription`,
   `claimConfiguration`, `claimPolicy`, `claimMigrationEmergencyKey`,
   `consumeGovernanceNonce`, `proposeWalletGuardMigration`,
   `acceptWalletGuardMigration`, `enablePermit2OnWallet`,
   `revokePermit2OnWallet`), но сам координатор со снапшотом, 48-часовым
   таймлоком и emergency-путём в этой поставке отсутствует. Он должен быть
   реализован и протестирован отдельно: лимит EVM по-прежнему диктует
   разделение. Не считайте миграцию готовой, пока этого нет.
2. **`proposeMigrationWithEmergency` (фикс из §2.4) относится к хабу.** Пока
   хаб не реализован, дефект экс-таймстемпа не закрыт.
3. **Кошелёк (`SmartHotWallet` / `SmartColdWallet`) и адаптер в поставке
   отсутствуют.** Проверены только интерфейсные вызовы
   (`sendNativeByGuard`, `proposeGuardMigration`, `acceptGuardMigration`,
   `emergencyEnablePermit2ForGuard`, `revokePermit2ForGuard`). Реальное
   поведение `onlyGuard`, лимитов и pause/unpause не подтверждено.
4. **Adapter требует перевыпуска при миграции.** `adapter.guard()` —
   immutable, поэтому `Registry.addAdapter` вызывает `ISwapAdapter(adapter).guard()`
   и отклонит старый адаптер. В снапшоте миграции нужна пара
   `oldAdapter → newAdapter` (структуры для этого в интерфейсе есть).
5. **Тесты не запускались.** Foundry в окружении не установлен, а существующий
   `SmartWalletService.t.sol` не соответствует реальному интерфейсу `Vm`
   (см. §2.1). Проверка v6 — это компиляция реальным solc 0.8.30 и разбор
   кода; Foundry-набор для v6 нужно написать.
6. **Nonce после миграции.** `usedNonces` живёт в `OwnerRegistry` и в снапшот
   не входит. Практическое следствие: после миграции нужно либо переносить
   счётчик использованных nonce, либо сменить диапазон nonce-ов у клиента,
   иначе подписи, сделанные до миграции и не исполненные, останутся
   валидными на новом Guard-е (они привязаны к адресу Guard-а, поэтому
   уязвимы только подписи, собранные уже под новый Guard).
7. **P2P on-chain endpoint отсутствует** (как и указано в ТЗ §104: escrow —
   отдельный контракт). Guard отдаёт только `canUseP2P()`.

## 5. Как это проверено (воспроизводимо)

Foundry в окружении отсутствует, поэтому компиляция выполнена настоящим
`solc` 0.8.30 (сборка emscripten, `soljson-v0.8.30+commit.73712a01.js`),
запущенным через Node:

```text
tools/solc-driver.js          — драйвер soljson (Standard JSON)
tools/build.js                — компиляция + отчёт по размерам runtime/init
tools/abi_check.py            — сверка: каждый вызов интерфейса модуля
                                существует в ABI контракта-цели
```

Команда:

```powershell
node tools/build.js tools/soljson-0.8.30.js build `
  contracts/GuardOps.sol contracts/GuardInterfaces.sol `
  contracts/SmartWalletGuardOwnerRegistry-v6.0.0.sol `
  contracts/SmartWalletPolicyRegistry-v6.0.0.sol `
  contracts/SmartWalletGuardSubscriptions-v6.0.0.sol `
  contracts/SmartWalletGuard-v6.0.0.sol
```

`tools/abi_check.py` нашёл реальный пропуск (`setHub` отсутствовал у двух
модулей, хотя Guard его вызывал) — то есть это не формальная, а рабочая
проверка целостности после разделения. Итог: `interface calls checked: 50,
problems: 0`.

Проверка не заменяет Foundry-тесты: она подтверждает, что код компилируется,
укладывается в лимиты и что модули согласованы по сигнатурам. Поведение
(подписи, лимиты, миграция) статической проверкой не подтверждается.

## 6. Изменения публичного API относительно v5.2.1

Ломающие — это осознанная цена устранения §2.2/§2.5:

| v5.2.1 | v6.0.0 |
|---|---|
| `transfer/addWhitelist/...` требуют установленного `service` | `service` больше нет; entitlement внутри системы |
| `setService(address,nonce,deadline,sigs)` | удалено |
| `collectSubscriptionPayment(...)` на Core | `subscribe(plan,fromWallet,nonce,deadline,sigs)` |
| `addHotWallet/addColdWallet` | `addWallet(wallet,isHot,nonce,deadline,sigs)` |
| `addWhitelist` и др. на Core | на `SmartWalletGuardSubscriptions` (Guard отдаёт `subscriptions()`) |
| revert-строки | custom errors |
| `whitelist[recipient][token]` публичный mapping | `getWhitelistEntry(...)` / `getWhitelistKeys()` |
| `adapters` | `adapterPolicy` + `getAdapterKeys()` |

## 7. Рекомендуемый порядок развёртывания

```text
1.  new SmartWalletGuardOwnerRegistry(permit2)
2.  new SmartWalletGuard(mainWallet, ownerRegistry, permit2, expectedOldGuard)
3.  ownerRegistry.setGuard(guard)        // привязка проверяется внутри setGuard
4.  new SmartWalletPolicyRegistry(guard)
5.  new SmartWalletGuardSubscriptions(mainWallet, permit2, policyRegistry, ownerRegistry)
6.  guard.configureModules(policyRegistry, subscriptions)
        // безопасно вызывать кому угодно: оба модуля обязаны ссылаться
        // ровно на этот Guard (isBoundTo)
7.  guard.initializeOwners(owners, isHot)
        // только hub; hub = адрес, создавший Guard
8.  guard.setHub(multisig)               // передача управления
9.  subscriptions.addToken / addRouter / addTradingPlatform / addWhitelist /
    addAdapter / addBlacklist  (2/3 Hot) и guard.setRecoveryTarget (3/5 + Cold)
10. subscriptions.setTreasury / setPlanConfig / setAppVersionHash / setP2PConfig
11. guard.addWallet(hot, true, ...) / guard.addWallet(cold, false, ...)
12. wallet.emergencyEnablePermit2ForGuard(token) для нужных токенов
13. Только после этого — пополнение кошельков (ТЗ §120/§121)
```

Шаги 6 и 7 разделены намеренно: привязка модулей безопасна для любого
вызывающего (адреса валидируются обратной привязкой), а состав владельцев
устанавливает только hub. Фронтраннинг инициализации невозможен.

Проверка перед первым депозитом: `guard()` и `permit2()` каждого кошелька,
`ownerRegistry.getOwners()`, `guard.permissionMask()`,
`subscriptions.getPlanConfig()`, списки `policyRegistry`, `treasury`,
recovery targets, `migrationEmergencyKey`.

## 8. Вердикт

* v5.2.1 **не был работоспособен**: не разворачивался (45 498 байт runtime при
  лимите 24 576; initcode 47 369 при лимите 49 152) и делегировал авторизацию
  кошелька внешнему контракту.
* v6.0.0 в предоставленном объёме **компилируется и влезает в лимиты**
  (проверено реальным solc 0.8.30), устраняет перечисленные в §3.1 дефекты
  и сохраняет поведение ТЗ. Расхождений сигнатур между модулями нет
  (`abi_check.py`, 50/50).
* **Production-ready считать нельзя**, пока не реализованы и не
  протестированы хаб миграции, кошелёк и адаптер, и пока нет Foundry-набора
  тестов (ТЗ §117/§118/§119). Это ровно те условия, которые перечисляет
  §125 «Definition of Done».

// SPDX-License-Identifier: MIT
pragma solidity 0.8.30;

/* =========================================================================
   GuardOps — общий кодек подписей SmartWalletGuard v6.0.0
   =========================================================================
   Единая точка для EIP-712 домена, структурных хешей и восстановления
   подписчиков. Используется Guard-ом, OwnerRegistry, SubscriptionManager и
   MigrationHub, поэтому digests, которые считает клиент, совпадают у всех
   участников (verifyingContract = адрес Guard-а).

   Типы операций (все включают nonce и deadline):

     Transfer(address wallet,address token,address recipient,uint256 amount,uint256 nonce,uint256 deadline)
     NativeTransfer(address wallet,address recipient,uint256 amount,uint256 nonce,uint256 deadline)
     Swap(address wallet,address adapter,address tokenIn,address tokenOut,uint256 amountIn,uint256 minAmountOut,address recipient,bytes32 adapterDataHash,uint256 nonce,uint256 deadline)
     EmergencySweep(address wallet,address token,address recipient,uint256 nonce,uint256 deadline)
     Subscribe(address mainWallet,uint8 plan,address paymentToken,uint256 price,address fromWallet,uint256 nonce,uint256 deadline)

     PolicyOp(address mainWallet,uint8 kind,uint8 op,bytes32 data1,bytes32 data2,uint256 value1,uint256 value2,uint256 nonce,uint256 deadline)

   Для PolicyOp layout полей фиксирован по (kind, op) и описан в
   `policyHash*` функциях ниже — на одну пару (kind, op) ровно один layout.
   ========================================================================= */

library GuardOps {

    bytes32 internal constant DOMAIN_TYPEHASH =
        keccak256("EIP712Domain(string name,string version,uint256 chainId,address verifyingContract)");
    bytes32 internal constant TRANSFER_TYPEHASH = keccak256(
        "Transfer(address wallet,address token,address recipient,uint256 amount,uint256 nonce,uint256 deadline)");
    bytes32 internal constant NATIVE_TRANSFER_TYPEHASH = keccak256(
        "NativeTransfer(address wallet,address recipient,uint256 amount,uint256 nonce,uint256 deadline)");
    bytes32 internal constant SWAP_TYPEHASH = keccak256(
        "Swap(address wallet,address adapter,address tokenIn,address tokenOut,uint256 amountIn,uint256 minAmountOut,address recipient,bytes32 adapterDataHash,uint256 nonce,uint256 deadline)");
    bytes32 internal constant SWEEP_TYPEHASH = keccak256(
        "EmergencySweep(address wallet,address token,address recipient,uint256 nonce,uint256 deadline)");
    bytes32 internal constant SUBSCRIBE_TYPEHASH = keccak256(
        "Subscribe(address mainWallet,uint8 plan,address paymentToken,uint256 price,address fromWallet,uint256 nonce,uint256 deadline)");
    bytes32 internal constant POLICY_TYPEHASH = keccak256(
        "PolicyOp(address mainWallet,uint8 kind,uint8 op,bytes32 data1,bytes32 data2,uint256 value1,uint256 value2,uint256 nonce,uint256 deadline)");
    bytes32 internal constant POLICY_DEEP_TYPEHASH = keccak256(
        "PolicyOpDeep(address mainWallet,uint8 kind,uint8 op,bytes32 data1,bytes32 data2,uint256 value1,uint256 value2,uint256 extra,uint256 nonce,uint256 deadline)");
    bytes32 internal constant OWNERS_TYPEHASH = keccak256(
        "ChangeOwners(address mainWallet,bytes32 ownersHash,bytes32 isHotHash,uint256 nonce,uint256 deadline)");
    bytes32 internal constant MIGRATION_TYPEHASH = keccak256(
        "Migration(address mainWallet,address newGuard,bytes32 migrationDataHash,uint256 nonce,uint256 executeAfter,uint256 deadline,bool emergency)");
    bytes32 internal constant CANCEL_MIGRATION_TYPEHASH = keccak256(
        "CancelMigration(address mainWallet,address newGuard,uint256 nonce,uint256 deadline)");
    /// @dev Расход внутрь доверенного контракта (замена adapter-пути).
    bytes32 internal constant ON_CONTRACT_TYPEHASH = keccak256(
        "OnContract(address mainWallet,address wallet,address target,address token,uint256 amount,address recipient,bool strict,uint256 nonce,uint256 deadline)");
    /// @dev Approve на конкретную сумму в пользу контракта.
    bytes32 internal constant APPROVE_TYPEHASH = keccak256(
        "ApproveOnContract(address mainWallet,address wallet,address spender,address token,uint256 amount,bool strict,uint256 nonce,uint256 deadline)");

    bytes32 internal constant SECP256K1N_HALF =
        0x7fffffffffffffffffffffffffffffff5d576e7357a4501ddfe92f46681b20a0;

    error BadSignatureLength();
    error BadSignatureValue();
    error HighSValue();
    error ZeroSigner();

    function domainSeparator(uint256 chainId, address verifyingContract) internal pure returns (bytes32) {
        return keccak256(abi.encode(
            DOMAIN_TYPEHASH,
            keccak256(bytes("SmartWalletGuard")),
            keccak256(bytes("6.0.0")),
            chainId,
            verifyingContract
        ));
    }

    function _digest(bytes32 ds, bytes32 structHash_) internal pure returns (bytes32) {
        return keccak256(abi.encodePacked("\x19\x01", ds, structHash_));
    }

    // --------------------------- структурные хеши ---------------------------

    function transferHash(
        address wallet, address token, address recipient, uint256 amount, uint256 nonce, uint256 deadline
    ) internal pure returns (bytes32) {
        return keccak256(abi.encode(TRANSFER_TYPEHASH, wallet, token, recipient, amount, nonce, deadline));
    }

    function nativeTransferHash(
        address wallet, address recipient, uint256 amount, uint256 nonce, uint256 deadline
    ) internal pure returns (bytes32) {
        return keccak256(abi.encode(NATIVE_TRANSFER_TYPEHASH, wallet, recipient, amount, nonce, deadline));
    }

    function swapHash(
        address wallet, address adapter, address tokenIn, address tokenOut, uint256 amountIn,
        uint256 minAmountOut, address recipient, bytes32 adapterDataHash, uint256 nonce, uint256 deadline
    ) internal pure returns (bytes32) {
        return keccak256(abi.encode(
            SWAP_TYPEHASH, wallet, adapter, tokenIn, tokenOut, amountIn,
            minAmountOut, recipient, adapterDataHash, nonce, deadline));
    }

    function sweepHash(address wallet, address token, address recipient, uint256 nonce, uint256 deadline)
        internal pure returns (bytes32)
    {
        return keccak256(abi.encode(SWEEP_TYPEHASH, wallet, token, recipient, nonce, deadline));
    }

    function subscribeHash(
        address mainWallet, uint8 plan, address paymentToken, uint256 price, address fromWallet,
        uint256 nonce, uint256 deadline
    ) internal pure returns (bytes32) {
        return keccak256(abi.encode(
            SUBSCRIBE_TYPEHASH, mainWallet, plan, paymentToken, price, fromWallet, nonce, deadline));
    }

    /// @dev PolicyOp с двумя «свободными» 32-байтовыми словами. Layout задаётся
    ///      вызывающим кодом ровно один раз на пару (kind, op).
    function policyHash(
        address mainWallet, uint8 kind, uint8 op, bytes32 data1, bytes32 data2,
        uint256 value1, uint256 value2, uint256 nonce, uint256 deadline
    ) internal pure returns (bytes32) {
        return keccak256(abi.encode(
            POLICY_TYPEHASH, mainWallet, kind, op, data1, data2, value1, value2, nonce, deadline));
    }

    function policyHashAddrs(
        address mainWallet, uint8 kind, uint8 op, address a, address b,
        uint256 value1, uint256 value2, uint256 nonce, uint256 deadline
    ) internal pure returns (bytes32) {
        return policyHash(
            mainWallet, kind, op, bytes32(bytes20(a)), bytes32(bytes20(b)),
            value1, value2, nonce, deadline);
    }

    function policyHashVals(
        address mainWallet, uint8 kind, uint8 op, uint256 value1, uint256 value2,
        uint256 value3, uint256 value4, uint256 nonce, uint256 deadline
    ) internal pure returns (bytes32) {
        return policyHash(
            mainWallet, kind, op, bytes32(value1), bytes32(value2),
            value3, value4, nonce, deadline);
    }

    /// @dev Вариант с дополнительным policy-значением (например срок действия):
    ///      data1 = адрес A, data2 = адрес B, value1/value2 = лимиты,
    ///      extra = срок/доп. параметр.
    function policyHashDeep(
        address mainWallet, uint8 kind, uint8 op, bytes32 data1, bytes32 data2,
        uint256 value1, uint256 value2, uint256 extra, uint256 nonce, uint256 deadline
    ) internal pure returns (bytes32) {
        return keccak256(abi.encode(
            POLICY_DEEP_TYPEHASH, mainWallet, kind, op, data1, data2, value1, value2, extra, nonce, deadline));
    }

    function changeOwnersHash(
        address mainWallet, bytes32 ownersHash, bytes32 isHotHash, uint256 nonce, uint256 deadline
    ) internal pure returns (bytes32) {
        return keccak256(abi.encode(OWNERS_TYPEHASH, mainWallet, ownersHash, isHotHash, nonce, deadline));
    }

    function onContractHash(
        address mainWallet, address wallet, address target, address token, uint256 amount,
        address recipient, bool strict, uint256 nonce, uint256 deadline
    ) internal pure returns (bytes32) {
        return keccak256(abi.encode(
            ON_CONTRACT_TYPEHASH, mainWallet, wallet, target, token, amount, recipient, strict, nonce, deadline));
    }

    function approveHash(
        address mainWallet, address wallet, address spender, address token, uint256 amount,
        bool strict, uint256 nonce, uint256 deadline
    ) internal pure returns (bytes32) {
        return keccak256(abi.encode(
            APPROVE_TYPEHASH, mainWallet, wallet, spender, token, amount, strict, nonce, deadline));
    }

    function migrationHash(
        address mainWallet, address newGuard, bytes32 migrationDataHash,
        uint256 nonce, uint256 executeAfter, uint256 deadline, bool emergency
    ) internal pure returns (bytes32) {
        return keccak256(abi.encode(
            MIGRATION_TYPEHASH, mainWallet, newGuard, migrationDataHash, nonce, executeAfter, deadline, emergency));
    }

    function cancelMigrationHash(address mainWallet, address newGuard, uint256 nonce, uint256 deadline)
        internal pure returns (bytes32)
    {
        return keccak256(abi.encode(CANCEL_MIGRATION_TYPEHASH, mainWallet, newGuard, nonce, deadline));
    }

    function digestOf(bytes32 ds, bytes32 structHash_) internal pure returns (bytes32) {
        return _digest(ds, structHash_);
    }

    // --------------------------- подписи ---------------------------

    function recover(bytes32 dgst, bytes calldata sig) internal pure returns (address) {
        if (sig.length != 65) revert BadSignatureLength();
        bytes32 r;
        bytes32 s;
        uint8 v;
        assembly ("memory-safe") {
            r := calldataload(sig.offset)
            s := calldataload(add(sig.offset, 32))
            v := byte(0, calldataload(add(sig.offset, 64)))
        }
        if (v < 27) v += 27;
        if (v != 27 && v != 28) revert BadSignatureValue();
        if (uint256(s) > uint256(SECP256K1N_HALF)) revert HighSValue();
        address signer = ecrecover(dgst, v, r, s);
        if (signer == address(0)) revert ZeroSigner();
        return signer;
    }
}

/* =========================================================================
   SmartWalletGuard v6.0.0 — Owner Registry
   =========================================================================
   Единственный источник истины по governance-владельцам (5 owners, 3 Hot /
   2 Cold) и по consumed nonce-ам. Вынесен из Guard-а, чтобы:
     - Guard и SubscriptionManager использовали один и тот же verifier
       (нельзя выдать entitlement в обход подписей);
     - runtime bytecode каждого контракта уложился в лимит EVM 24 576 байт.

   Доступ: все мутирующие функции вызывает только `guard`, который сам
   проверяет, что действие авторизовано (подписи владельцев или hub-миграция).
   ========================================================================= */

contract SmartWalletGuardOwnerRegistry {

    string public constant VERSION = "6.0.0";
    address public constant NATIVE = address(0);

    uint256 public constant HOT_THRESHOLD = 2;
    uint256 public constant CRITICAL_THRESHOLD = 3;
    uint256 public constant TOTAL_OWNERS = 5;
    uint256 public constant HOT_OWNERS = 3;

    struct OwnerInfo { bool isOwner; bool isHot; }

    address public immutable permit2;

    /// @dev Устанавливается один раз через `setGuard`.
    address public guard;

    address[] private _owners;
    mapping(address => OwnerInfo) public ownerInfo;
    mapping(address => mapping(uint256 => bool)) public usedNonces;

    address[] private _hotWallets;
    address[] private _coldWallets;
    mapping(address => uint256) private _hotIdx;
    mapping(address => uint256) private _coldIdx;

    event OwnerChanged(address indexed owner, bool isHot, bool active);
    event HotWalletUpdated(address indexed wallet, bool active);
    event ColdWalletUpdated(address indexed wallet, bool active);

    error NotGuard();
    error AlreadyInitialized();
    error NotInitialized();
    error BadOwnerSet();
    error ZeroAddress();
    error NotContract();
    error NonceUsed();
    error ThresholdNotMet();
    error TooManySignatures();
    error NotAnOwner();
    error DuplicateSigner();
    error ColdOwnerRequired();
    error WalletAlreadyRegistered();
    error WalletNotRegistered();
    error WrongGuard();
    error WrongPermit2();
    error DeadlineExpired();

    modifier onlyGuard() {
        if (msg.sender != guard) revert NotGuard();
        _;
    }

    constructor(address permit2_) {
        if (permit2_ == address(0) || permit2_.code.length == 0) revert NotContract();
        permit2 = permit2_;
    }

    /// @notice Разовая привязка к Guard-у. Вызывающий обязан быть Guard-ом,
    ///         который сам ссылается на этот OwnerRegistry, — поэтому
    ///         привязаться может только «правильный» Guard.
    function setGuard(address guard_) external {
        if (guard != address(0)) revert AlreadyInitialized();
        if (guard_ == address(0) || guard_.code.length == 0) revert NotContract();
        if (ISmartWalletMin(guard_).guard() != address(this)) revert WrongGuard();
        guard = guard_;
    }

    // =========================================================================
    // Инициализация
    // =========================================================================

    /// @notice Устанавливает исходный состав владельцев. Однократно.
    function initialize(address[] calldata newOwners, bool[] calldata newIsHot) external onlyGuard {
        if (_owners.length != 0) revert AlreadyInitialized();
        _validate(newOwners, newIsHot);
        _apply(newOwners, newIsHot);
    }

    /// @notice Замена состава владельцев (обычная ротация).
    function changeOwners(address[] calldata newOwners, bool[] calldata newIsHot) external onlyGuard {
        if (_owners.length == 0) revert NotInitialized();
        _validate(newOwners, newIsHot);
        _apply(newOwners, newIsHot);
    }

    function _validate(address[] calldata newOwners, bool[] calldata newIsHot) internal pure {
        if (newOwners.length != TOTAL_OWNERS || newIsHot.length != TOTAL_OWNERS) revert BadOwnerSet();
        uint256 hot;
        for (uint256 i = 0; i < TOTAL_OWNERS; i++) {
            address o = newOwners[i];
            if (o == address(0)) revert ZeroAddress();
            for (uint256 j = 0; j < i; j++) {
                if (newOwners[j] == o) revert BadOwnerSet();
            }
            if (newIsHot[i]) hot++;
        }
        if (hot != HOT_OWNERS) revert BadOwnerSet();
    }

    function _apply(address[] calldata newOwners, bool[] calldata newIsHot) internal {
        uint256 oldLen = _owners.length;
        for (uint256 i = 0; i < oldLen; i++) {
            address old = _owners[i];
            delete ownerInfo[old];
            emit OwnerChanged(old, false, false);
        }
        delete _owners;
        for (uint256 i = 0; i < TOTAL_OWNERS; i++) {
            address o = newOwners[i];
            ownerInfo[o] = OwnerInfo(true, newIsHot[i]);
            _owners.push(o);
            emit OwnerChanged(o, newIsHot[i], true);
        }
    }

    // =========================================================================
    // Wallet registry (2/3 Hot)
    // =========================================================================

    /// @notice Добавляет Smart Wallet. Обёртка вокруг `_addWallet`, доступная
    ///         только Guard-у (Guard сам проверяет подписи и реестр).
    function addWallet(address wallet, bool isHot) external onlyGuard {
        _addWallet(wallet, isHot);
    }

    function _addWallet(address wallet, bool isHot) internal {
        if (wallet == address(0)) revert ZeroAddress();
        if (wallet.code.length == 0) revert NotContract();
        if (ISmartWalletMin(wallet).guard() != guard) revert WrongGuard();
        if (ISmartWalletMin(wallet).permit2() != permit2) revert WrongPermit2();
        if (_hotIdx[wallet] != 0 || _coldIdx[wallet] != 0) revert WalletAlreadyRegistered();

        if (isHot) {
            _hotWallets.push(wallet);
            _hotIdx[wallet] = _hotWallets.length;
            emit HotWalletUpdated(wallet, true);
        } else {
            _coldWallets.push(wallet);
            _coldIdx[wallet] = _coldWallets.length;
            emit ColdWalletUpdated(wallet, true);
        }
    }

    function removeWallet(address wallet) external onlyGuard {
        bool isHot = _hotIdx[wallet] != 0;
        bool isCold = _coldIdx[wallet] != 0;
        if (!isHot && !isCold) revert WalletNotRegistered();
        if (isHot) _removeEnum(_hotWallets, _hotIdx, wallet);
        else _removeEnum(_coldWallets, _coldIdx, wallet);
        if (isHot) emit HotWalletUpdated(wallet, false);
        else emit ColdWalletUpdated(wallet, false);
    }

    function _removeEnum(address[] storage list, mapping(address => uint256) storage idx, address w) internal {
        uint256 pos = idx[w];
        uint256 last = list.length;
        if (pos != last) {
            address moved = list[last - 1];
            list[pos - 1] = moved;
            idx[moved] = pos;
        }
        list.pop();
        delete idx[w];
    }

    // =========================================================================
    // Nonce
    // =========================================================================

    /// @notice Потребляет nonce в указанном scope (mainWallet или hot wallet).
    function consumeNonce(address scope, uint256 nonce) external onlyGuard {
        if (usedNonces[scope][nonce]) revert NonceUsed();
        usedNonces[scope][nonce] = true;
    }

    /// @notice Не reverting-вариант: нужен координатору миграции, который
    ///         проверяет подписи через Guard и затем потребляет nonce.
    function tryConsumeNonce(address scope, uint256 nonce) external onlyGuard returns (bool) {
        if (usedNonces[scope][nonce]) return false;
        usedNonces[scope][nonce] = true;
        return true;
    }

    // =========================================================================
    // Проверка подписей
    // =========================================================================

    function verifySignatures(bytes32 dgst, bytes[] calldata sigs, bool critical) public view returns (bool) {
        uint256 len = sigs.length;
        if (len < (critical ? CRITICAL_THRESHOLD : HOT_THRESHOLD)) return false;
        if (len > TOTAL_OWNERS) return false;
        address[] memory seen = new address[](len);
        uint256 hot;
        uint256 cold;
        for (uint256 i = 0; i < len; i++) {
            address s = GuardOps.recover(dgst, sigs[i]);
            OwnerInfo memory info = ownerInfo[s];
            if (!info.isOwner) return false;
            for (uint256 j = 0; j < i; j++) {
                if (seen[j] == s) return false;
            }
            seen[i] = s;
            if (info.isHot) hot++;
            else cold++;
        }
        if (critical) return cold > 0;
        return hot >= HOT_THRESHOLD;
    }

    /// @notice Reverting-вариант для внутреннего использования Guard-ом.
    function requireSignatures(bytes32 dgst, bytes[] calldata sigs, bool critical) external view {
        uint256 len = sigs.length;
        if (len < (critical ? CRITICAL_THRESHOLD : HOT_THRESHOLD)) revert ThresholdNotMet();
        if (len > TOTAL_OWNERS) revert TooManySignatures();
        address[] memory seen = new address[](len);
        uint256 hot;
        uint256 cold;
        for (uint256 i = 0; i < len; i++) {
            address s = GuardOps.recover(dgst, sigs[i]);
            OwnerInfo memory info = ownerInfo[s];
            if (!info.isOwner) revert NotAnOwner();
            for (uint256 j = 0; j < i; j++) {
                if (seen[j] == s) revert DuplicateSigner();
            }
            seen[i] = s;
            if (info.isHot) hot++;
            else cold++;
        }
        if (critical) {
            if (cold == 0) revert ColdOwnerRequired();
        } else if (hot < HOT_THRESHOLD) {
            revert ThresholdNotMet();
        }
    }

    // =========================================================================
    // Views
    // =========================================================================

    function getOwners() external view returns (address[] memory) { return _owners; }
    function ownerCount() external view returns (uint256) { return _owners.length; }
    function isOwnerHot(address owner) external view returns (bool) { return ownerInfo[owner].isHot; }
    function isOwner(address owner) external view returns (bool) { return ownerInfo[owner].isOwner; }
    function isNonceUsed(address scope, uint256 nonce) external view returns (bool) { return usedNonces[scope][nonce]; }
    function getHotWallets() external view returns (address[] memory) { return _hotWallets; }
    function getColdWallets() external view returns (address[] memory) { return _coldWallets; }
    function isRegisteredWallet(address wallet) external view returns (bool) {
        return _hotIdx[wallet] != 0 || _coldIdx[wallet] != 0;
    }
    function isHotWallet(address wallet) external view returns (bool) { return _hotIdx[wallet] != 0; }
    function isColdWallet(address wallet) external view returns (bool) { return _coldIdx[wallet] != 0; }
}

interface ISmartWalletMin {
    function guard() external view returns (address);
    function permit2() external view returns (address);
}

    /// @notice Policy на smart contract — одна запись на контракт.
    /// @param exists            запись настроена
    /// @param blocked           полная блокировка контракта (§19)
    /// @param usdLimit          общий лимит в микро-USD (1e6 = $1); 0 — автотрата
    ///                          запрещена без strict-подписи (§15)
    /// @param usdSpent          израсходовано в микро-USD (§16, §17)
    /// @param maxTokenShareBps  максимальная доля текущего баланса токена в BPS

    /// @param deadline          срок действия policy (§20)
    struct ContractPolicy {

        bool blocked;
        uint256 usdLimit;

    modifier onlyGuard() {
        if (msg.sender != guard) revert NotAuthorized();
        _;
    }

    /// @dev Записи разрешены Guard-у, координатору `hub` и MigrationHub-у,
    ///      которым Guard сам себя обслуживает. MigrationHub определяется
    ///      через сам Guard (`migrationHub()`), поэтому подделать его нельзя.
    modifier onlyWriter() {
        if (msg.sender != guard && msg.sender != hub
            && msg.sender != IGuardStateForRegistry(guard).migrationHub()) {
            revert NotAuthorized();
        }
        _;
    }

    /// @dev Записи отклоняются, если Guard уже мигрировал наружу. Флаг живёт в
    ///      MigrationHub — единственном источнике истины. Во время применения
    ///      снапшота на НОВОМ Guard-е флаг ещё false, поэтому миграция проходит.
    modifier live() {
        address mh = IGuardStateForRegistry(guard).migrationHub();
        if (mh != address(0) && IMigrationHubState(mh).finalizedOut(guard)) revert GuardMigratedOut();
        _;
    }

        if (guard_ == address(0)) revert ZeroAddress();
        guard = guard_;

    function claim(address expectedMainWallet, address expectedPermit2) external onlyGuard {
        if (claimed) revert AlreadyClaimed();
        if (IGuardStateForRegistry(guard).mainWallet() != expectedMainWallet) revert NotAuthorized();
        if (IGuardStateForRegistry(guard).permit2() != expectedPermit2) revert NotAuthorized();
        claimed = true;
    }

    /// @notice Устанавливает/перезаписывает policy на контракт.
    /// @param targetContract контракт, которому пользователь доверяет в рамках policy
    /// @param usdLimit       лимит в микро-USD; 0 = автотрата запрещена (§15)
    /// @param maxTokenShareBps доля баланса токена в BPS (2000 = 20 %)
    /// @param deadline       срок действия
    function setContractPolicy(
        address targetContract,
        bool blocked,
        uint256 usdLimit,
        uint256 maxTokenShareBps,
        uint256 deadline
    ) external onlyWriter live {
        if (targetContract == address(0) || targetContract.code.length == 0) revert NotContract();
        if (deadline < block.timestamp) revert DeadlineInPast();
        if (maxTokenShareBps > BPS_DENOMINATOR) revert BadConfig();

        bool isNew = !contractPolicy[targetContract].exists;
        ContractPolicy storage p = contractPolicy[targetContract];
        p.exists = true;
        p.blocked = blocked;
        p.maxTokenShareBps = maxTokenShareBps;
        p.deadline = deadline;
        // Лимит можно как угодно менять через governance-подпись; уже
        // израсходованное не сбрасывается, чтобы нельзя было обнулить
        // историю расходов.
        p.usdLimit = usdLimit;

        if (isNew) _addEnum(_contractList, _contractIdx, targetContract);
        emit ContractPolicyUpdated(targetContract, true, blocked, usdLimit, maxTokenShareBps, deadline);
    }

    function setContractBlocked(address targetContract, bool blocked) external onlyWriter live {
        ContractPolicy storage p = contractPolicy[targetContract];
        if (!p.exists) revert NotSet();
        p.blocked = blocked;
        emit ContractPolicyUpdated(targetContract, true, blocked, p.usdLimit, p.maxTokenShareBps, p.deadline);
    }

    /// @notice Разовое применение policy при миграции: без проверки «уже
    ///         существует», со сбросом истории расходов нового Guard-а.
    function claimContractPolicy(
        address targetContract, bool blocked, uint256 usdLimit, uint256 maxTokenShareBps, uint256 deadline
    ) external onlyWriter live {
        if (targetContract == address(0) || targetContract.code.length == 0) revert NotContract();
        if (maxTokenShareBps > BPS_DENOMINATOR) revert BadConfig();
        if (!contractPolicy[targetContract].exists) _addEnum(_contractList, _contractIdx, targetContract);
        contractPolicy[targetContract] = ContractPolicy(true, blocked, usdLimit, 0, maxTokenShareBps, deadline);
        emit ContractPolicyUpdated(targetContract, true, blocked, usdLimit, maxTokenShareBps, deadline);
    }

    function setContractDeadline(address targetContract, uint256 deadline) external onlyWriter live {
        ContractPolicy storage p = contractPolicy[targetContract];
        if (!p.exists) revert NotSet();
        if (deadline < block.timestamp) revert DeadlineInPast();
        p.deadline = deadline;
        emit ContractPolicyUpdated(targetContract, true, p.blocked, p.usdLimit, p.maxTokenShareBps, deadline);
    }

    /// @notice Увеличивает USD-лимит, сохраняя уже израсходованное (§17).
    function increaseContractUsdLimit(address targetContract, uint256 newUsdLimit) external onlyWriter live {
        ContractPolicy storage p = contractPolicy[targetContract];
        if (!p.exists) revert NotSet();
        if (newUsdLimit <= p.usdLimit) revert MustIncrease();
        p.usdLimit = newUsdLimit;
        emit ContractPolicyUpdated(targetContract, true, p.blocked, newUsdLimit, p.maxTokenShareBps, p.deadline);
    }

    function removeContractPolicy(address targetContract) external onlyWriter live {
        if (!contractPolicy[targetContract].exists) revert NotSet();
        _removeEnum(_contractList, _contractIdx, targetContract);
        delete contractPolicy[targetContract];
        emit ContractPolicyUpdated(targetContract, false, false, 0, 0, 0);
    }

    /// @notice Абсолютный лимит количества токена для пары (targetContract, token).

    function setTokenAmountPolicy(
        address targetContract,
        address token,
        uint256 maxAmount,
        uint256 maxBalanceShareBps
    ) external onlyWriter live {
        if (targetContract == address(0) || token == address(0)) revert ZeroAddress();
        if (maxBalanceShareBps > BPS_DENOMINATOR) revert BadConfig();
        if (maxAmount == 0 && maxBalanceShareBps == 0) revert BadConfig();
        TokenAmountPolicy storage t = tokenAmountPolicy[targetContract][token];
        bool isNew = !t.exists;
        t.exists = true;
        t.maxAmount = maxAmount;
        t.maxBalanceShareBps = maxBalanceShareBps;
        if (isNew) emit TokenAmountPolicyUpdated(targetContract, token, maxAmount, maxBalanceShareBps);
        else emit TokenAmountPolicyUpdated(targetContract, token, maxAmount, maxBalanceShareBps);
    }

        if (!tokenAmountPolicy[targetContract][token].exists) revert NotSet();
        delete tokenAmountPolicy[targetContract][token];
        emit TokenAmountPolicyUpdated(targetContract, token, 0, 0);
    }

    // Проверки исполнения
    // =========================================================================

    /// @notice Основная проверка расхода: ContractPolicy + TokenRisk + лимиты.
    /// @dev Возвращает израсходованное в микро-USD (для GREEN), 0 иначе.
    ///      Изменяет `usdSpent`. Вызывается Guard-ом перед Permit2-переводом.
    /// @param wallet  кошелёк-источник; баланс читается on-chain (ТЗ §11)
    /// @param target  доверенный smart contract
    /// @param token   расходуемый токен
    /// @param amount  количество токена
    /// @param strictExternal true, если strict-подпись (локальный ключ) уже проверена
    function checkAndSpend(
        address wallet,
        address target,
        address token,
        uint256 amount,
        bool strictExternal
    ) external onlyGuard live returns (uint256 usdValue) {
        if (token == NATIVE) revert NativeNotAllowed();
        if (amount == 0) revert BadConfig();
        if (blacklist[target] || blacklist[token]) revert ContractBlocked();

        ContractPolicy storage p = contractPolicy[target];
        if (!p.exists) revert ContractNotWhitelisted();
        if (p.blocked) revert ContractBlocked();
        if (block.timestamp > p.deadline) revert PolicyExpired();

        // Лимит доли баланса действует для любой категории (§6, §7, §8, §10)
        // и считается от баланса ДО операции, чтобы нельзя было дробить вывод.
        _checkBalanceShare(wallet, token, amount, p.maxTokenShareBps, true);

        TokenRisk memory risk = _tokenRisk[token];
        if (risk.configured && risk.category == TokenRiskCategory.GREEN) {
            uint256 price = _priceE18(token);
            usdValue = _toUsdMicro(amount, price, _tokenPrice[token].decimals);
            if (usdValue == 0) revert PriceNotConfigured();
            // usdLimit == 0 => автотрата запрещена без strict-подписи (§15)
            if (p.usdLimit == 0) {
                if (!strictExternal) revert UsdLimitExceeded();
            } else {
                uint256 remaining = p.usdLimit > p.usdSpent ? p.usdLimit - p.usdSpent : 0;
                if (usdValue > remaining) {
                    if (!strictExternal) revert UsdLimitExceeded();
                }
            }
            p.usdSpent += usdValue;
        } else {
            // YELLOW / RED / UNKNOWN — строгий режим: только абсолютное
            // количество + доля баланса (§7, §8, §9).
            TokenAmountPolicy memory t = tokenAmountPolicy[target][token];
            if (t.exists && t.maxAmount > 0 && amount > t.maxAmount) {
                if (!strictExternal) revert LimitExceeded();
            }
            if (t.exists && t.maxBalanceShareBps > 0) {
                _checkBalanceShare(wallet, token, amount, t.maxBalanceShareBps, false);
            } else if (!t.exists && !strictExternal) {
                // Нет ни категории, ни token-лимита => нет разрешения вообще.
                revert LimitExceeded();
            }
        }

        emit ContractPolicySpent(target, token, amount, usdValue);
    }

    /// @notice Проверка обычного перевода на получателя (без ContractPolicy).
    /// @dev Получатель в transfer — не доверенный контракт, а адрес назначения,
    ///      поэтому применяется доля баланса, чтобы дешёвый токен не позволил
    ///      вывести весь баланс (§10).
    function checkTransferShare(
        address wallet,
        address token,
        uint256 amount,
        uint256 shareBps
    ) external view onlyGuard returns (bool) {
        _checkBalanceShare(wallet, token, amount, shareBps, true);
        return true;
    }

    /// @notice Помечает расход как одобренный strict-ключом (ТЗ §14/§15/§52).
    ///         Вызывается Guard-ом, который уже проверил подпись.
    function consumeStrict(address target, address token, uint256 amount) external onlyGuard live {
        ContractPolicy storage p = contractPolicy[target];
        if (!p.exists) revert ContractNotWhitelisted();
        if (p.blocked) revert ContractBlocked();
        if (block.timestamp > p.deadline) revert PolicyExpired();
        TokenRisk memory risk = _tokenRisk[token];
        if (risk.configured && risk.category == TokenRiskCategory.GREEN) {
            uint256 usdValue = _toUsdMicro(amount, _priceE18(token), _tokenPrice[token].decimals);
            p.usdSpent += usdValue;
        }
    }

    /// @notice Блокирует unlimited approval (§13) и считает расход по policy.
    function checkApproval(
        address wallet,
        address spender,
        address token,
        uint256 amount,
        uint256 usdLimit,
        uint256 maxTokenShareBps
    ) external view onlyGuard returns (bool) {
        if (amount == type(uint256).max) revert UnlimitedApprove();
        ContractPolicy storage p = contractPolicy[spender];
        if (!p.exists) revert ContractNotWhitelisted();
        if (p.blocked) revert ContractBlocked();
        if (block.timestamp > p.deadline) revert PolicyExpired();
        uint256 share = p.maxTokenShareBps;
        if (maxTokenShareBps != 0 && (share == 0 || maxTokenShareBps < share)) share = maxTokenShareBps;
        _checkBalanceShare(wallet, token, amount, share, true);
        if (usdLimit != 0) {
            TokenRisk memory risk = _tokenRisk[token];
            if (risk.configured && risk.category == TokenRiskCategory.GREEN) {
                uint256 usdValue = _toUsdMicro(amount, _priceE18(token), _tokenPrice[token].decimals);
                uint256 remaining = p.usdLimit > p.usdSpent ? p.usdLimit - p.usdSpent : 0;
                if (usdValue > remaining) revert UsdLimitExceeded();
            }
        }
        return true;
    }

    /// @notice Остаток USD-лимита для UI (§18). 0, если policy не настроена.
    function remainingUsd(address targetContract) external view returns (uint256 remaining) {

        return p.usdLimit > p.usdSpent ? p.usdLimit - p.usdSpent : 0;

    /// @notice Максимальное количество токена, которое сейчас допустимо.
    function maxSpendableAmount(address wallet, address targetContract, address token)
        external view returns (uint256 byBalance)
    {
        ContractPolicy storage p = contractPolicy[targetContract];
        uint256 shareBps = p.maxTokenShareBps;
        TokenAmountPolicy memory t = tokenAmountPolicy[targetContract][token];
        if (t.exists && t.maxBalanceShareBps != 0 && (shareBps == 0 || t.maxBalanceShareBps < shareBps)) {
            shareBps = t.maxBalanceShareBps;
        }
        if (shareBps == 0) return 0;
        uint256 balance = IERC20Balance(token).balanceOf(wallet);
        byBalance = (balance * shareBps) / BPS_DENOMINATOR;
        if (t.exists && t.maxAmount != 0 && byBalance > t.maxAmount) byBalance = t.maxAmount;
    }

    function getContractPolicyKeys() external view returns (address[] memory) { return _contractList; }
    function getTokenRiskKeys() external view returns (address[] memory) { return _riskList; }
    function getTokenPriceKeys() external view returns (address[] memory) { return _priceList; }
    function getBlacklist() external view returns (address[] memory) { return _blacklistList; }
    function getApprovedTokens() external view returns (address[] memory) { return _tokenList; }
    function getApprovedRouters() external view returns (address[] memory) { return _routerList; }
    function getTradingPlatforms() external view returns (address[] memory) { return _platformList; }
    function getRecoveryKeys() external view returns (address[] memory) { return _recoveryKeys; }

    // =========================================================================
    // Internal
    // =========================================================================

    function _key(address a, address b) internal pure returns (bytes32) {
        return keccak256(abi.encodePacked(a, b));
    }

    function _priceE18(address token) internal view returns (uint256 price) {
        TokenPrice memory t = _tokenPrice[token];
        if (!t.configured || t.priceE18 == 0) revert PriceNotConfigured();
        price = t.priceE18;
    }

    /// @dev amount * priceE18 / 10^decimals => микро-USD (1e6 = $1).
    function _toUsdMicro(uint256 amount, uint256 priceE18, uint8 decimals) internal pure returns (uint256) {
        uint256 numerator = amount * priceE18;
        uint256 denom = 10 ** uint256(decimals);
        uint256 usdE18 = numerator / denom;
        return usdE18 / 1e12;
    }

    /// @dev Доля считается от баланса ДО операции, поэтому дробление вывода на
    ///      много транзакций не обходит лимит.
    function _checkBalanceShare(
        address wallet,
        address token,
        uint256 amount,
        uint256 shareBps,
        bool required
    ) internal view {
        if (shareBps == 0) {
            if (required) revert BalanceShareExceeded();
            return;
        }
        uint256 balance = IERC20Balance(token).balanceOf(wallet);
        if (balance == 0) revert BalanceShareExceeded();
        uint256 allowed = (balance * shareBps) / BPS_DENOMINATOR;
        if (amount > allowed) revert BalanceShareExceeded();
    }

    function _addEnum(address[] storage list, mapping(address => uint256) storage idx, address value) internal {
        list.push(value);
        idx[value] = list.length;
    }

    function _removeEnum(address[] storage list, mapping(address => uint256) storage idx, address value) internal {
        uint256 pos = idx[value];
        if (pos == 0) return;
        uint256 last = list.length;
        if (pos != last) {
            address moved = list[last - 1];
            list[pos - 1] = moved;
            idx[moved] = pos;
        }
        list.pop();
        delete idx[value];
    }

    function _removePair(
        address[] storage list,
        address a,
        address b,
        bytes32 k,
        mapping(bytes32 => bool) storage has
    ) internal {
        if (has[k]) has[k] = false;
        uint256 n = list.length / 2;
        for (uint256 i = 0; i < n; i++) {
            if (list[2 * i] == a && list[2 * i + 1] == b) {
                uint256 last = n - 1;
                if (i != last) {
                    list[2 * i] = list[2 * last];
                    list[2 * i + 1] = list[2 * last + 1];
                }
                list.pop();
                list.pop();
                return;
            }
        }
    }
}

    function subscribe(

        uint8 plan, address fromWallet, uint256 nonce, uint256 deadline, bytes[] calldata signatures

    ) external nonReentrant {

        _requireLive();

        if (plan != PLAN_STANDARD && plan != PLAN_PREMIUM) revert BadPlan();

        PlanConfig memory config = planConfigs[plan];

        if (!config.enabled || config.paymentToken == address(0) || config.price == 0 || config.period == 0) {

            revert PlanDisabled();

        }

        if (config.price > type(uint160).max) revert AmountOutOfRange();

        if (treasury == address(0)) revert TreasuryUnavailable();



        ISubPolicyRegistry reg = ISubPolicyRegistry(policyRegistry);

        if (reg.blacklist(treasury)) revert TreasuryUnavailable();

        if (reg.blacklist(config.paymentToken)) revert TokenBlacklisted();

        if (!reg.approvedToken(config.paymentToken)) revert TokenNotApproved();



        if (!ISubGuard(guard).isRegisteredWallet(fromWallet)) revert WalletNotRegistered();

        if (fromWallet.code.length == 0) revert NotContract();

        if (ISubWallet(fromWallet).guard() != guard) revert WrongGuard();

        if (ISubWallet(fromWallet).permit2() != permit2) revert WrongPermit2();

        if (ISubWallet(fromWallet).paused()) revert WalletPaused();



        _checkDeadline(deadline);

        ISubOwnerRegistry(ownerRegistry).consumeNonce(fromWallet, nonce);



        bytes32 dgst = GuardOps.digestOf(

            DOMAIN_SEPARATOR,

            GuardOps.subscribeHash(mainWallet, plan, config.paymentToken, config.price, fromWallet, nonce, deadline)

        );

        ISubOwnerRegistry(ownerRegistry).requireSignatures(dgst, signatures, false);



        // Renwal того же тарифа продлевается от текущего expiry, смена тарифа

        // или истёкшая подписка — от now (ТЗ §51).

        Subscription memory old = subscription;

        uint256 nextExpiry;

        if (old.plan == plan && old.expiresAt > block.timestamp) {

            nextExpiry = uint256(old.expiresAt) + uint256(config.period);

        } else {

            nextExpiry = block.timestamp + uint256(config.period);

        }

        if (nextExpiry > type(uint64).max) revert ExpiryOverflow();



        _checkPermit2(fromWallet, config.paymentToken, config.price);

        IPermit2Sub(permit2).transferFrom(

            fromWallet, treasury, uint160(config.price), config.paymentToken);



        subscription = Subscription(plan, uint64(nextExpiry));

        emit Subscribed(mainWallet, plan, config.paymentToken, config.price, uint64(nextExpiry), fromWallet);

    }

        _consumeHot(KIND_TOKEN_PRICE, 1, token, address(0), priceE18, decimals, 0, nonce, deadline, signatures);

        external

    {

        _requireLive();

        _consumeHot(KIND_DEFAULT_SHARE, 1, address(0), address(0), bps, 0, 0, nonce, deadline, signatures);

        ISubPolicyRegistry(policyRegistry).setDefaultTransferShareBps(bps);

    }

        external

    {

        if (target == address(0)) revert ZeroAddress();

        _requireLive();

        ISubPolicyRegistry(policyRegistry).removeRecoveryTarget(wallet, token);

        emit RecoveryTargetUpdated(wallet, token, address(0), false);

    }

    function claimPolicy(

        uint8 kind, address a, address b, uint256 limit, uint256 deadline, address recipient

    ) external onlyGuard {

        ISubPolicyRegistry reg = ISubPolicyRegistry(policyRegistry);

        if (kind == 1) reg.addToken(a);

        else if (kind == 2) reg.addRouter(a);

        else if (kind == 3) reg.addBlacklist(a);

        else if (kind == 4) reg.addTradingPlatform(a);


        else if (kind == 6) reg.claimContractPolicy(a, deadline == 1, limit, uint160(recipient), deadline);

        else if (kind == 7) reg.setRecoveryTarget(a, b, recipient);

        else revert NotImplemented();

        emit PolicyClaimed(kind, a, b, limit, deadline);

    }



    // =========================================================================

    // Внутреннее

    // =========================================================================



    function _requireLive() internal view {

        if (ISubGuard(guard).migratedOut()) revert MigratedOutError();

    }



    function _checkDeadline(uint256 deadline) internal view {

        if (block.timestamp > deadline) revert DeadlineExpired();

    }



    function _checkPermit2(address wallet, address token, uint256 amount) internal view {

        (uint160 allowed, uint48 expiration, ) = IPermit2Sub(permit2).allowance(wallet, token, guard);

        if (uint256(allowed) < amount) revert Permit2AllowanceInsufficient();

        // expiration == 0 у Permit2 означает истёкший allowance (ТЗ §41, FIX 1).

        if (expiration == 0 || uint256(expiration) < block.timestamp) revert Permit2AllowanceExpired();

    }



    /// @dev 6-аргументный вариант: (a,b) — адреса, (v1,v2) — значения, (d) —

    ///      дополнительное значение policy (например срок действия).

    function _consumeHot(

        uint8 kind, uint8 op, address a, address b, uint256 v1, uint256 v2,

        uint256 nonce, uint256 deadline, bytes[] calldata signatures

    ) internal {

        _consumeHot(kind, op, a, b, v1, v2, 0, nonce, deadline, signatures);

    }



    function _consumeHot(

        uint8 kind, uint8 op, address a, address b, uint256 v1, uint256 v2, uint256 d,

        uint256 nonce, uint256 deadline, bytes[] calldata signatures

    ) internal {

        _checkDeadline(deadline);

        ISubOwnerRegistry(ownerRegistry).consumeNonce(mainWallet, nonce);

        bytes32 structHash_ = GuardOps.policyHashDeep(mainWallet, kind, op, bytes32(bytes20(a)), bytes32(bytes20(b)), v1, v2, d, nonce, deadline);

        ISubOwnerRegistry(ownerRegistry).requireSignatures(

            GuardOps.digestOf(DOMAIN_SEPARATOR, structHash_), signatures, false);

    }



    function _consumeCritical(

        uint8 kind, uint8 op, address a, address b, uint256 v1, uint256 v2,

        uint256 nonce, uint256 deadline, bytes[] calldata signatures

    ) internal {

        _checkDeadline(deadline);

        ISubOwnerRegistry(ownerRegistry).consumeNonce(mainWallet, nonce);

        bytes32 structHash_ = GuardOps.policyHashAddrs(mainWallet, kind, op, a, b, v1, v2, nonce, deadline);

        ISubOwnerRegistry(ownerRegistry).requireSignatures(

            GuardOps.digestOf(DOMAIN_SEPARATOR, structHash_), signatures, true);

    }



    // =========================================================================

    // Digest helpers для клиентов / backend

    // =========================================================================



    function subscribeDigest(

        uint8 plan, address paymentToken, uint256 price, address fromWallet, uint256 nonce, uint256 deadline

    ) external view returns (bytes32) {

        return GuardOps.digestOf(

            DOMAIN_SEPARATOR,

            GuardOps.subscribeHash(mainWallet, plan, paymentToken, price, fromWallet, nonce, deadline)

        );

    }



    /// @notice Digest policy-операции. `kind`/`op` — из внутреннего каталога

    ///         (contract 21, tokenRisk 27, tokenPrice 28, tokenAmount 29,

    ///         defaultShare 44, treasury 40/0, planConfig 41/<plan>,

    ///         p2p 42/0, appVersion 43/0).

    function policyDigest(

        uint8 kind, uint8 op, address a, address b, uint256 v1, uint256 v2,

        uint256 nonce, uint256 deadline

    ) external view returns (bytes32) {

        return GuardOps.digestOf(

            DOMAIN_SEPARATOR,

            GuardOps.policyHashAddrs(mainWallet, kind, op, a, b, v1, v2, nonce, deadline)

        );

    }



    function appVersionDigest(bytes32 newHash, uint256 nonce, uint256 deadline) external view returns (bytes32) {

        return GuardOps.digestOf(

            DOMAIN_SEPARATOR,

            GuardOps.policyHashVals(mainWallet, KIND_APP_VERSION, 0, uint256(newHash), 0, 0, 0, nonce, deadline)

        );

    }

}

         ISubscriptionsView, IMigrationHubView } from "./GuardInterfaces.sol";

/* =========================================================================
   SmartWalletGuard v6.1.0 — Core
   =========================================================================
   Изменения относительно v6.0.0 (ТЗ v6.1):

   1.  ADAPTER ARCHITECTURE УДАЛЕНА полностью: нет `ISwapAdapterView`,
       `executeSwap`, `adapterPolicy`, `addAdapter/removeAdapter`, проверок
       `adapter.guard()` и передачи токенов сначала адаптеру. Вместо этого
       один универсальный путь — `executeOnContract`: Guard не знает функций
       конкретного DEX, он знает только target contract, token и amount.
   2.  Выбор пути определяется моделью policy: `executeOnContract` — расход
       ВНУТРЬ доверенного smart contract (ContractPolicy), `transfer`/
       `transferNative` — перевод НА адрес получателя (доля баланса).
       Recipient и spender больше не смешиваются.
   3.  Проверки лимитов: USD-лимит (только GREEN с настроенной ценой),
       TokenAmountPolicy (YELLOW/RED), доля текущего баланса (всегда),
       deadline, blocked.
   4.  Strict-режим: для RED/UNKNOWN, при `usdLimit == 0` и при превышении
       любого лимита требуется дополнительная подпись локального
       security-ключа (`strictKey`), который разблокируется на устройстве.
       Ключ хранится только на устройстве; on-chain — лишь его адрес.
   5.  Unlimited approve блокируется; approve на конкретную сумму проходит
       через policy и учитывается в `usdSpent`.
   6.  Migration state больше НЕ хранится в Guard-е: `migratedOut`,
       `migrationAccepted`, `migratedTo`, `markMigratedOut`,
       `acceptMigrationIn` удалены. Источник истины — MigrationHub.
   ========================================================================= */

abstract contract GuardReentrancy {
    uint256 private _locked = 1;
    modifier nonReentrant() {
        if (_locked != 1) revert GuardReentrancyError();
        _locked = 2;
        _;
        _locked = 1;
    }
}

error GuardReentrancyError();

contract SmartWalletGuard is GuardReentrancy {

    string public constant VERSION = "6.1.0";
    address public constant NATIVE = address(0);

    uint256 public constant PERM_APP_VERIFY = 1 << 0;
    uint256 public constant PERM_EMERGENCY  = 1 << 1;
    uint256 public constant PERM_COLD_WARM  = 1 << 2;
    uint256 public constant PERM_P2P        = 1 << 3;
    uint256 public constant PERM_SECURITY   = 1 << 4;
    uint256 public constant PERM_TRADING    = 1 << 5;

    uint8 internal constant KIND_WALLET = 1;
    uint8 internal constant KIND_REVOKE_PERMIT2 = 2;
    uint8 internal constant KIND_RECOVERY = 26;
    uint8 internal constant KIND_STRICT_KEY = 27;
    uint8 internal constant KIND_ON_CONTRACT = 28;

    address public immutable mainWallet;
    address public immutable permit2;
    address public immutable expectedOldGuard;
    address public immutable ownerRegistry;

    // Устанавливаются один раз в `configureModules`.
    address public policyRegistry;
    address public subscriptions;
    address public migrationHub;

    address public hub;
    bool public initialized;

    /// @notice Модуль применения снапшота миграции (см.
    ///         SmartWalletGuardMigrationModule). Ему Guard делегирует
    ///         миграционные claim-операции, чтобы не превышать лимит EVM.
    address public migrationModule;

    /// @notice Адрес локального security-ключа для strict-режима (ТЗ v6.1 §15).
    ///         address(0) — strict-режим заблокирован (операция просто
    ///         отклоняется, если требует strict-подпись).

    address public pendingStrictKey;

    address public migrationEmergencyKey;
    address public pendingMigrationEmergencyKey;

    event TransferExecuted(address indexed wallet, address indexed token, address indexed recipient, uint256 amount, uint256 nonce);
    event NativeTransferExecuted(address indexed wallet, address indexed recipient, uint256 amount, uint256 nonce);

    event WalletGuardMigrationAccepted(address indexed wallet);
    event WalletPermit2Enabled(address indexed wallet, address indexed token);
    event WalletPermit2Revoked(address indexed wallet, address indexed token);

    event MigrationEmergencyKeyCancelled(address indexed current);
    event RecoveryTargetUpdated(address indexed wallet, address indexed token, address indexed recipient, bool active);
    event WalletRegistryClaimed(address indexed wallet, bool isHot);

    error NotMigrationHub();
    error AlreadyInitialized();
    error MigratedOutError();
    error MigrationNotAccepted();
    error DeadlineExpired();
    error ZeroAddress();
    error PolicyRejected();
    error NotContract();
    error WrongGuard();

    error WalletPaused();
    error WalletNotRegistered();
    error TokenBlacklisted();
    error TokenNotApproved();
    error RecipientBlacklisted();
    error AmountOutOfRange();
    error Permit2AllowanceInsufficient();
    error Permit2AllowanceExpired();
    error NoRecoveryTarget();
    error RecoveryRecipientBlacklisted();
    error ZeroBalance();
    error SweepTooLarge();
    error PermissionRequired();
    error NotPausedWallet();
    error BadOwnerSet();

    /// @dev Обычные операции запрещены после миграции; во время применения
    ///      снапшота исключение делается только для самого hub-а.
    modifier notMigrated() {
        if (msg.sender != hub) {
            if (IMigrationHubView(migrationHub).finalizedOut(address(this))) revert MigratedOutError();
            if (expectedOldGuard != address(0)
                && !IMigrationHubView(migrationHub).acceptedFrom(address(this), expectedOldGuard)) {
                revert MigrationNotAccepted();
            }
        }
        _;
    }

    modifier onlyHub() {
        if (msg.sender != hub || hub == address(0)) revert NotHub();
        _;
    }

    /// @dev Применение снапшота миграции: только координатор, и только когда
    ///      миграция действительно финализирована на этот Guard.
    modifier onlyMigration() {
        if (msg.sender != migrationModule || migrationModule == address(0)) revert NotMigrationHub();
        if (!IMigrationHubView(migrationHub).authorizedMigration(address(this))) revert MigrationNotAccepted();
        _;
    }

    constructor(address mainWallet_, address ownerRegistry_, address permit2_, address expectedOldGuard_) {
        if (mainWallet_ == address(0)) revert ZeroAddress();
        if (ownerRegistry_ == address(0) || ownerRegistry_.code.length == 0) revert NotContract();
        if (permit2_ == address(0) || permit2_.code.length == 0) revert NotContract();
        if (expectedOldGuard_ != address(0) && expectedOldGuard_.code.length == 0) revert NotContract();

        mainWallet = mainWallet_;
        permit2 = permit2_;
        ownerRegistry = ownerRegistry_;
        expectedOldGuard = expectedOldGuard_;

        DOMAIN_SEPARATOR = GuardOps.domainSeparator(block.chainid, address(this));

        hub = msg.sender;
        emit HubUpdated(address(0), msg.sender);
    }

    // =========================================================================
    // Инициализация
    // =========================================================================

    /// @notice Привязка модулей. Безопасна для любого вызывающего: каждый
    ///         модуль обязан ссылаться ровно на этот Guard (`isBoundTo`).
    function configureModules(
        address policyRegistry_, address subscriptions_, address migrationHub_, address migrationModule_
    ) external {
        if (initialized) revert AlreadyInitialized();
        if (policyRegistry != address(0) || subscriptions != address(0) || migrationHub != address(0)) {
            revert AlreadyInitialized();
        }
        if (policyRegistry_ == address(0) || policyRegistry_.code.length == 0) revert NotContract();
        if (subscriptions_ == address(0) || subscriptions_.code.length == 0) revert NotContract();
        if (migrationHub_ == address(0) || migrationHub_.code.length == 0) revert NotContract();
        if (!IPolicyRegistryView(policyRegistry_).isBoundTo(address(this))) revert WrongGuard();
        if (!ISubscriptionsView(subscriptions_).isBoundTo(address(this))) revert WrongGuard();
        if (!IMigrationHubView(migrationHub_).isBoundTo(address(this))) revert WrongGuard();
        if (migrationModule_ == address(0) || migrationModule_.code.length == 0) revert NotContract();
        policyRegistry = policyRegistry_;
        subscriptions = subscriptions_;
        migrationHub = migrationHub_;
        migrationModule = migrationModule_;
    }

    /// @notice Фиксация состава владельцев. Только hub (развёртыватель или
    ///         координатор миграции целевого Guard-а).
    function initializeOwners(address[] calldata owners_, bool[] calldata isHot_) external onlyHub {
        if (initialized) revert AlreadyInitialized();
        IOwnerRegistryView(ownerRegistry).initialize(owners_, isHot_);
        initialized = true;
    }

    // =========================================================================
    // Views
    // =========================================================================


    /// @dev Маска прав вычисляется в самом Guard-е из активного плана. Это
    ///      убирает зависимость авторизации от логики внешнего контракта:
    ///      Manager отдаёт только план, решение о правах принимает Guard
    ///      (ТЗ v5.1.4 §100).
    function _mask() internal view returns (uint256) {
        if (ISubscriptionsView(subscriptions).activePlan() == 0) {
            return PERM_APP_VERIFY | PERM_EMERGENCY;
        }
        return PERM_APP_VERIFY | PERM_EMERGENCY | PERM_COLD_WARM | PERM_P2P | PERM_SECURITY | PERM_TRADING;
    }


    function hasPermission(uint256 permission) external view returns (bool) {
        return permission != 0 && (_mask() & permission) == permission;
    }





    function domainSeparator() external view returns (bytes32) { return DOMAIN_SEPARATOR; }

    // =========================================================================
    // Digest helpers (клиенты считают digest сами; эти функции для сверки)
    // =========================================================================







    // =========================================================================
    // ERC20 transfer на адрес получателя — 2/3 Hot + PERM_COLD_WARM|PERM_SECURITY
    // =========================================================================

    function transfer(
        address hotWallet, address token, address recipient, uint256 amount,
        uint256 nonce, uint256 deadline, bytes[] calldata signatures
    ) external nonReentrant notMigrated {
        _requirePermission(PERM_COLD_WARM | PERM_SECURITY);
        if (amount == 0 || amount > type(uint160).max) revert AmountOutOfRange();
        if (token == NATIVE) revert ZeroAddress();
        _checkHotWallet(hotWallet);
        if (recipient == address(0)) revert ZeroAddress();
        if (IPolicyRegistryView(policyRegistry).blacklist(recipient)) revert RecipientBlacklisted();
        _checkToken(token);
        _checkDeadline(deadline);

        // Доля баланса: даже дешёвый токен не позволяет вывести весь баланс
        // одним переводом на произвольный адрес (ТЗ v6.1 §10).
        uint256 shareBps = IPolicyRegistryView(policyRegistry).defaultTransferShareBps();
        IPolicyRegistryView(policyRegistry).checkTransferShare(hotWallet, token, amount, shareBps);

        _checkPermit2Allowance(hotWallet, token, amount);
        _verifyHot(
            GuardOps.transferHash(hotWallet, token, recipient, amount, nonce, deadline),
            hotWallet, nonce, signatures
        );

        IPermit2View(permit2).transferFrom(hotWallet, recipient, uint160(amount), token);
        emit TransferExecuted(hotWallet, token, recipient, amount, nonce);
    }

    // =========================================================================
    // Native transfer — 2/3 Hot + PERM_COLD_WARM|PERM_SECURITY
    // =========================================================================

    function transferNative(
        address hotWallet, address payable recipient, uint256 amount,
        uint256 nonce, uint256 deadline, bytes[] calldata signatures
    ) external nonReentrant notMigrated {
        _requirePermission(PERM_COLD_WARM | PERM_SECURITY);
        if (amount == 0) revert AmountOutOfRange();
        _checkHotWallet(hotWallet);
        if (recipient == address(0)) revert ZeroAddress();
        if (IPolicyRegistryView(policyRegistry).blacklist(recipient)) revert RecipientBlacklisted();
        _checkDeadline(deadline);

        _verifyHot(
            GuardOps.nativeTransferHash(hotWallet, recipient, amount, nonce, deadline),
            hotWallet, nonce, signatures
        );

        ISmartWalletView(hotWallet).sendNativeByGuard(recipient, amount);
        emit NativeTransferExecuted(hotWallet, recipient, amount, nonce);
    }

    // =========================================================================
    // Расход ВНУТРЬ доверенного smart contract — универсальный путь вместо
    // adapter architecture (ТЗ v6.1 §1, §22, §24, §54)
    // =========================================================================

    /// @notice Расход токена в пользу доверенного контракта (DEX, протокол,
    ///         любой smart contract). Guard не знает, что этот контракт делает:
    ///         он применяет ContractPolicy + TokenRisk + лимиты.
    /// @param target    доверенный контракт, которому уходит token
    /// @param token     расходуемый токен
    /// @param amount    количество
    /// @param recipient получатель результата операции (для адаптеров больше
    ///                  не используется, остаётся информационным и входит в подпись)
    /// @param strict    требуется ли strict-подпись локального ключа; значение
    ///                  входит в digest, поэтому подпись нельзя переиспользовать
    /// @param strictSignature  подпись strictKey (проверяется, если strict = true)
    function executeOnContract(
        address hotWallet, address target, address token, uint256 amount, address recipient,
        bool strict, uint256 nonce, uint256 deadline,
        bytes calldata strictSignature, bytes[] calldata signatures
    ) external nonReentrant notMigrated {
        _requirePermission(PERM_TRADING | PERM_SECURITY);
        if (amount == 0 || amount > type(uint160).max) revert AmountOutOfRange();
        if (token == NATIVE || target == NATIVE) revert ZeroAddress();
        if (target.code.length == 0) revert NotContract();
        _checkHotWallet(hotWallet);
        _checkToken(token);
        _checkDeadline(deadline);

        bytes32 digest = _digestOf(GuardOps.onContractHash(
            mainWallet, hotWallet, target, token, amount, recipient, strict, nonce, deadline
        ));

        if (strict) _checkStrictKey(digest, strictSignature);
        _verifyHot(digest, hotWallet, nonce, signatures);

        // Policy-проверки выполняет Registry: ContractPolicy + категория токена
        // + USD-лимит + доля баланса + absolute amount + deadline + blocked.
        uint256 usdValue = IPolicyRegistryView(policyRegistry).checkAndSpend(
            hotWallet, target, token, amount, strict
        );

        _checkPermit2Allowance(hotWallet, token, amount);
        IPermit2View(permit2).transferFrom(hotWallet, target, uint160(amount), token);

        emit ContractExecuted(hotWallet, target, token, amount, usdValue, recipient, strict, nonce);
    }

    // =========================================================================
    // Approve через Guard — защита от unlimited и учёт в policy (ТЗ v6.1 §12-§14)
    // =========================================================================

    /// @notice Approve на конкретную сумму в пользу доверенного контракта.
    ///         Unlimited approve отклоняется. Списывается в `usdSpent`.
    /// @dev Кошелёк должен вызывать approve только через Guard; это требование
    ///      к реализации Smart Wallet (см. REVIEW).
    function approveOnContract(
        address hotWallet, address spender, address token, uint256 amount,
        bool strict, uint256 nonce, uint256 deadline,
        bytes calldata strictSignature, bytes[] calldata signatures
    ) external nonReentrant notMigrated {
        _requirePermission(PERM_TRADING | PERM_SECURITY);
        if (amount == type(uint256).max) revert UnlimitedApprove();
        if (amount == 0) revert AmountOutOfRange();
        if (token == NATIVE || spender == NATIVE) revert ZeroAddress();
        if (spender.code.length == 0) revert NotContract();
        _checkHotWallet(hotWallet);
        _checkToken(token);
        _checkDeadline(deadline);

        bytes32 digest = _digestOf(GuardOps.approveHash(
            mainWallet, hotWallet, spender, token, amount, strict, nonce, deadline
        ));

        if (strict) _checkStrictKey(digest, strictSignature);
        _verifyHot(digest, hotWallet, nonce, signatures);

        // Проверка + учёт расхода в одной операции: множество approve не может
        // обойти общий лимит, потому что второй approve уже не пройдёт.
        IPolicyRegistryView(policyRegistry).checkAndSpend(hotWallet, spender, token, amount, strict);

        (bool ok, bytes memory ret) = token.call(
            abi.encodeWithSelector(0x095ea7b3, spender, amount)
        );
        if (!ok || (ret.length != 0 && !abi.decode(ret, (bool)))) revert PolicyRejected();

        emit ApprovalGranted(hotWallet, spender, token, amount, strict);
    }

    // =========================================================================
    // Emergency sweep — 2/3 Hot, без подписки, policy и whitelist
    // =========================================================================

    function emergencySweep(
        address wallet, address token, uint256 nonce, uint256 deadline, bytes[] calldata signatures
    ) external nonReentrant notMigrated {
        if (!IOwnerRegistryView(ownerRegistry).isRegisteredWallet(wallet)) revert WalletNotRegistered();
        if (!ISmartWalletView(wallet).paused()) revert NotPausedWallet();

        IPolicyRegistryView reg = IPolicyRegistryView(policyRegistry);
        (bool exists, address storedRecipient) = reg.getRecoveryTarget(wallet, token);
        if (!exists) revert NoRecoveryTarget();
        if (reg.blacklist(storedRecipient)) revert RecoveryRecipientBlacklisted();
        if (token != NATIVE && reg.blacklist(token)) revert TokenBlacklisted();

        _checkDeadline(deadline);
        _verifyHot(
            GuardOps.sweepHash(wallet, token, storedRecipient, nonce, deadline),
            wallet, nonce, signatures
        );

        uint256 amount;
        if (token == NATIVE) {
            amount = wallet.balance;
            if (amount == 0) revert ZeroBalance();
            ISmartWalletView(wallet).sendNativeByGuard(payable(storedRecipient), amount);
        } else {
            amount = IERC20View(token).balanceOf(wallet);
            if (amount == 0) revert ZeroBalance();
            if (amount > type(uint160).max) revert SweepTooLarge();
            ISmartWalletView(wallet).emergencyEnablePermit2ForGuard(token);
            _checkPermit2Allowance(wallet, token, amount);
            IPermit2View(permit2).transferFrom(wallet, storedRecipient, uint160(amount), token);
        }
        emit EmergencySweepExecuted(wallet, token, storedRecipient, amount);
    }

    // =========================================================================
    // Recovery target — 3/5 + Cold
    // =========================================================================

    function setRecoveryTarget(
        address wallet, address token, address recipient,
        uint256 nonce, uint256 deadline, bytes[] calldata signatures
    ) external notMigrated {
        if (!IOwnerRegistryView(ownerRegistry).isRegisteredWallet(wallet)) revert WalletNotRegistered();
        if (recipient == address(0)) revert ZeroAddress();
        IPolicyRegistryView reg = IPolicyRegistryView(policyRegistry);
        if (reg.blacklist(recipient)) revert RecipientBlacklisted();
        if (token != NATIVE && !reg.approvedToken(token)) revert TokenNotApproved();
        _checkDeadline(deadline);
        IOwnerRegistryView(ownerRegistry).consumeNonce(mainWallet, nonce);
        IOwnerRegistryView(ownerRegistry).requireSignatures(
            _digestOf(GuardOps.policyHashAddrs(
                address(this), KIND_RECOVERY, 20, wallet, token, uint160(recipient), 0, nonce, deadline
            )),
            signatures,
            true
        );
        ISubscriptionsView(subscriptions).setRecoveryTarget(wallet, token, recipient);
        emit RecoveryTargetUpdated(wallet, token, recipient, true);
    }

    function removeRecoveryTarget(
        address wallet, address token, uint256 nonce, uint256 deadline, bytes[] calldata signatures
    ) external notMigrated {
        (bool targetExists, ) = IPolicyRegistryView(policyRegistry).getRecoveryTarget(wallet, token);
        if (!targetExists) revert NoRecoveryTarget();
        _checkDeadline(deadline);
        IOwnerRegistryView(ownerRegistry).consumeNonce(mainWallet, nonce);
        IOwnerRegistryView(ownerRegistry).requireSignatures(
            _digestOf(GuardOps.policyHashAddrs(
                address(this), KIND_RECOVERY, 21, wallet, token, 0, 0, nonce, deadline
            )),
            signatures,
            true
        );
        ISubscriptionsView(subscriptions).removeRecoveryTarget(wallet, token);
        emit RecoveryTargetUpdated(wallet, token, address(0), false);
    }

    // =========================================================================
    // Strict key (локальный security-ключ) — 3/5 + Cold
    // =========================================================================

    /// @notice Предлагает новый strict-ключ. Применяется самим ключом, поэтому
    ///         скомпрометированные owners не могут подменить его молча.
    function proposeStrictKey(address newKey, uint256 nonce, uint256 deadline, bytes[] calldata signatures)
        external notMigrated
    {
        if (newKey == address(0)) revert ZeroAddress();
        if (newKey.code.length != 0) revert NotContract();
        _checkDeadline(deadline);
        IOwnerRegistryView(ownerRegistry).consumeNonce(mainWallet, nonce);
        IOwnerRegistryView(ownerRegistry).requireSignatures(
            _digestOf(GuardOps.policyHashAddrs(
                address(this), KIND_STRICT_KEY, 1, newKey, address(0), 0, 0, nonce, deadline
            )),
            signatures,
            true
        );
        pendingStrictKey = newKey;
        emit StrictKeyProposed(strictKey, newKey);
    }

    function acceptStrictKey() external {
        if (msg.sender != pendingStrictKey) revert StrictSignatureInvalid();
        address old = strictKey;
        strictKey = pendingStrictKey;
        pendingStrictKey = address(0);
        emit StrictKeyChanged(old, strictKey);
    }

    function cancelStrictKey(uint256 nonce, uint256 deadline, bytes[] calldata signatures) external notMigrated {
        if (pendingStrictKey == address(0)) revert ZeroAddress();
        _checkDeadline(deadline);
        IOwnerRegistryView(ownerRegistry).consumeNonce(mainWallet, nonce);
        IOwnerRegistryView(ownerRegistry).requireSignatures(
            _digestOf(GuardOps.policyHashAddrs(
                address(this), KIND_STRICT_KEY, 2, address(0), address(0), 0, 0, nonce, deadline
            )),
            signatures,
            true
        );
        pendingStrictKey = address(0);
        emit StrictKeyCancelled(strictKey);
    }

    function _checkStrictKey(bytes32 digest, bytes calldata strictSignature) internal view {
        address key = strictKey;
        if (key == address(0)) revert StrictKeyNotSet();
        address signer = GuardOps.recover(digest, strictSignature);
        if (signer != key) revert StrictSignatureInvalid();
    }

    // =========================================================================
    // Owners и wallet registry — 3/5 + Cold / 2/3 Hot
    // =========================================================================

    function changeOwners(
        address[] calldata newOwners, bool[] calldata newIsHot,
        uint256 nonce, uint256 deadline, bytes[] calldata signatures
    ) external notMigrated {
        if (newOwners.length != 5 || newIsHot.length != 5) revert BadOwnerSet();
        _checkDeadline(deadline);
        IOwnerRegistryView(ownerRegistry).consumeNonce(mainWallet, nonce);
        IOwnerRegistryView(ownerRegistry).requireSignatures(
            _digestOf(GuardOps.changeOwnersHash(
                mainWallet, keccak256(abi.encode(newOwners)), keccak256(abi.encode(newIsHot)), nonce, deadline
            )),
            signatures,
            true
        );
        IOwnerRegistryView(ownerRegistry).changeOwners(newOwners, newIsHot);
    }

    function addWallet(address wallet, bool isHot, uint256 nonce, uint256 deadline, bytes[] calldata signatures)
        external nonReentrant notMigrated
    {
        _checkDeadline(deadline);
        IOwnerRegistryView(ownerRegistry).consumeNonce(mainWallet, nonce);
        IOwnerRegistryView(ownerRegistry).requireSignatures(
            _digestOf(GuardOps.policyHashAddrs(
                address(this), KIND_WALLET, 1, wallet, address(0), isHot ? 1 : 0, 0, nonce, deadline
            )),
            signatures,
            false
        );
        IOwnerRegistryView(ownerRegistry).addWallet(wallet, isHot);
    }

    function removeWallet(address wallet, uint256 nonce, uint256 deadline, bytes[] calldata signatures)
        external nonReentrant notMigrated
    {
        if (!IOwnerRegistryView(ownerRegistry).isRegisteredWallet(wallet)) revert WalletNotRegistered();
        _checkDeadline(deadline);
        IOwnerRegistryView(ownerRegistry).consumeNonce(mainWallet, nonce);
        IOwnerRegistryView(ownerRegistry).requireSignatures(
            _digestOf(GuardOps.policyHashAddrs(
                address(this), KIND_WALLET, 2, wallet, address(0), 0, 0, nonce, deadline
            )),
            signatures,
            false
        );
        IOwnerRegistryView(ownerRegistry).removeWallet(wallet);
    }

    // =========================================================================
    // Подписка
    // =========================================================================

    function subscribe(
        uint8 plan, address fromWallet, uint256 nonce, uint256 deadline, bytes[] calldata signatures
    ) external notMigrated {
        ISubscriptionsView(subscriptions).subscribe(plan, fromWallet, nonce, deadline, signatures);
    }

    // =========================================================================
    // Миграция: состояние живёт в MigrationHub
    // =========================================================================

    function setHub(address newHub) external {
        if (msg.sender != hub && !(newHub == msg.sender && !initialized)) revert NotHub();
        if (newHub == address(0)) revert ZeroAddress();
        address old = hub;
        hub = newHub;
        if (subscriptions != address(0)) ISubscriptionsView(subscriptions).setHub(newHub);
        emit HubUpdated(old, newHub);
    }





    function claimPolicy(
        uint8 kind, address a, address b, uint256 limit, uint256 deadline, address recipient
    ) external onlyMigration {
        ISubscriptionsView(subscriptions).claimPolicy(kind, a, b, limit, deadline, recipient);
    }


    function claimStrictKey(address key) external onlyMigration {
        if (key.code.length != 0) revert NotContract();
        emit StrictKeyChanged(strictKey, key);
        strictKey = key;
    }




    /// @notice Завершает миграцию кошелька на этом (новом) Guard-е.
    ///         Вызывается MigrationHub-ом (ТЗ v6.1 §32).
    function acceptWalletGuardMigration(address wallet) external onlyMigration {
        if (expectedOldGuard == address(0)) revert MigrationNotAccepted();
        if (wallet.code.length == 0) revert NotContract();
        if (ISmartWalletView(wallet).guard() != expectedOldGuard) revert WrongGuard();
        ISmartWalletView(wallet).acceptGuardMigration();
        if (ISmartWalletView(wallet).guard() != address(this)) revert WrongGuard();
        emit WalletGuardMigrationAccepted(wallet);
    }


    /// @notice Потребляет governance-nonce по требованию координатора миграции.
    function consumeGovernanceNonce(uint256 nonce) external returns (bool) {
        if (migrationHub == address(0)) return false;
        address hubAddr = hub;
        if (msg.sender != migrationHub && msg.sender != hubAddr) return false;
        return IOwnerRegistryView(ownerRegistry).tryConsumeNonce(mainWallet, nonce);
    }




    function revokePermit2OnWallet(
        address wallet, address token, uint256 nonce, uint256 deadline, bytes[] calldata signatures
    ) external nonReentrant notMigrated {
        if (token == NATIVE) revert ZeroAddress();
        if (ISmartWalletView(wallet).guard() != address(this)) revert WrongGuard();
        _checkDeadline(deadline);
        IOwnerRegistryView(ownerRegistry).consumeNonce(mainWallet, nonce);
        IOwnerRegistryView(ownerRegistry).requireSignatures(
            _digestOf(GuardOps.policyHashAddrs(
                address(this), KIND_REVOKE_PERMIT2, 1, wallet, token, 0, 0, nonce, deadline
            )),
            signatures,
            false
        );
        ISmartWalletView(wallet).revokePermit2ForGuard(token);
        emit WalletPermit2Revoked(wallet, token);
    }

    function acceptMigrationEmergencyKey() external {
        if (msg.sender != pendingMigrationEmergencyKey) revert NotHub();
        address old = migrationEmergencyKey;
        migrationEmergencyKey = pendingMigrationEmergencyKey;
        pendingMigrationEmergencyKey = address(0);
        emit MigrationEmergencyKeyChanged(old, migrationEmergencyKey);
    }

    // =========================================================================
    // Internal
    // =========================================================================

    function _digestOf(bytes32 structHash) internal view returns (bytes32) {
        return GuardOps.digestOf(DOMAIN_SEPARATOR, structHash);
    }

    function _requirePermission(uint256 permission) internal view {
        uint256 mask = _mask();
        if (permission == 0 || (mask & permission) != permission) revert PermissionRequired();
    }

    function _checkDeadline(uint256 deadline) internal view {
        if (block.timestamp > deadline) revert DeadlineExpired();
    }

    function _checkHotWallet(address wallet) internal view {
        if (!IOwnerRegistryView(ownerRegistry).isHotWallet(wallet)) revert WalletNotRegistered();
        if (wallet.code.length == 0) revert NotContract();
        if (ISmartWalletView(wallet).guard() != address(this)) revert WrongGuard();
        if (ISmartWalletView(wallet).permit2() != permit2) revert WrongPermit2();
        if (ISmartWalletView(wallet).paused()) revert WalletPaused();
    }

    function _checkToken(address token) internal view {
        IPolicyRegistryView reg = IPolicyRegistryView(policyRegistry);
        if (reg.blacklist(token)) revert TokenBlacklisted();
        if (!reg.approvedToken(token)) revert TokenNotApproved();
    }

    function _checkPermit2Allowance(address wallet, address token, uint256 amount) internal view {
        (uint160 allowed, uint48 expiration, ) = IPermit2View(permit2).allowance(wallet, token, address(this));
        if (uint256(allowed) < amount) revert Permit2AllowanceInsufficient();
        // expiration == 0 у Permit2 означает истёкший allowance (ТЗ §41).
        if (expiration == 0 || uint256(expiration) < block.timestamp) revert Permit2AllowanceExpired();
    }

    function _verifyHot(bytes32 digest, address scope, uint256 nonce, bytes[] calldata signatures) internal {
        IOwnerRegistryView(ownerRegistry).consumeNonce(scope, nonce);
        IOwnerRegistryView(ownerRegistry).requireSignatures(digest, signatures, false);
    }
}

// SPDX-License-Identifier: MIT
pragma solidity 0.8.30;

import { IGuardView, IOwnerRegistryView, IPolicyRegistryView, ISubscriptionsView,
         IMigrationHubView, ISmartWalletView } from "./GuardInterfaces.sol";

/* =========================================================================
   SmartWalletGuard v6.1.0 — Migration Module
   =========================================================================
   Применение снапшота миграции на НОВОМ Guard-е. Вынесено из Guard-а, потому
   что миграционный блок — самая крупная часть кода (~7 КБ) и Guard перестаёт
   влезать в лимит EVM 24 576 байт.

   Права:
     - модуль разворачивает целевой Guard (или владельцы) и регистрирует его
       через `guard.setMigrationModule(module)`;
     - вызовы принимаются только если MigrationHub подтверждает, что миграция
       на `newGuard` реально финализирована (`authorizedMigration`);
     - запись в OwnerRegistry / PolicyRegistry / Subscriptions выполняется
       модулем напрямую, поскольку Guard выдал ему роль migration manager.

   Адаптеров в v6.1 нет, поэтому adapter policies не мигрируют (ТЗ v6.1 §34).
   ========================================================================= */

contract SmartWalletGuardMigrationModule {

    string public constant VERSION = "6.1.0";

    address public immutable domainGuard;
    address public immutable migrationHub;
    address public immutable ownerRegistry;
    address public immutable policyRegistry;
    address public immutable subscriptions;

    bool public initialized;

    struct MigrationData {
        address[] owners;
        bool[] isHot;
        address[] hotWallets;
        address[] coldWallets;
        address[] approvedTokens;
        address[] approvedRouters;
        address[] blacklistAddrs;
        address[] tradingPlatforms;
        address[] policyContracts;
        uint256[] policyUsdLimits;
        uint256[] policyShareBps;
        uint256[] policyDeadlines;
        bool[] policyBlocked;
        address[] riskTokens;
        uint8[] riskCategories;
        address[] priceTokens;
        uint256[] priceE18;
        uint8[] priceDecimals;
        address[] amountTargets;
        address[] amountTokens;
        uint256[] amountMax;
        uint256[] amountShareBps;
        address[] recoveryWallets;
        address[] recoveryTokens;
        address[] recoveryRecipients;
        uint8 subscriptionPlan;
        uint64 subscriptionExpiresAt;
        address treasury;
        bytes32 appVersionHash;
        address p2pAdmin;
        address p2pDAO;
        uint64 p2pTimeout;
        uint256 defaultTransferShareBps;
        address migrationEmergencyKey;
        address strictKey;
    }

    event SnapshotApplied(address indexed oldGuard, address indexed newGuard, bytes32 migrationDataHash);

    error NotAuthorized();
    error AlreadyInitialized();
    error ZeroAddress();
    error SnapshotMismatch();

    modifier onlyAuthorizedMigration(address oldGuard) {
        if (!IMigrationHubView(migrationHub).authorizedMigration(domainGuard)) revert NotAuthorized();
        if (IMigrationHubView(migrationHub).acceptedFrom(domainGuard, oldGuard) != true) revert NotAuthorized();
        _;
    }

    constructor(
        address domainGuard_,
        address migrationHub_,
        address ownerRegistry_,
        address policyRegistry_,
        address subscriptions_
    ) {
        if (domainGuard_ == address(0) || domainGuard_.code.length == 0) revert ZeroAddress();
        if (migrationHub_ == address(0) || migrationHub_.code.length == 0) revert ZeroAddress();
        domainGuard = domainGuard_;
        migrationHub = migrationHub_;
        ownerRegistry = ownerRegistry_;
        policyRegistry = policyRegistry_;
        subscriptions = subscriptions_;
    }

    /// @notice Применяет снапшот на новом Guard-е. Вызывается MigrationHub-ом
    ///         сразу после финализации.
    function applySnapshot(address oldGuard, bytes32 migrationDataHash, bytes calldata migrationData)
        external
        onlyAuthorizedMigration(oldGuard)
    {
        if (initialized) revert AlreadyInitialized();
        if (keccak256(migrationData) != migrationDataHash) revert SnapshotMismatch();

        MigrationData memory d = abi.decode(migrationData, (MigrationData));
        _apply(oldGuard, d);
        initialized = true;
        emit SnapshotApplied(oldGuard, domainGuard, migrationDataHash);
    }

    /// @notice Включает Permit2-разрешение для кошелька на новом Guard-е.
    function enablePermit2OnWallet(address wallet, address token) external onlyAuthorizedMigration(IGuardView(domainGuard).expectedOldGuard()) {
        if (!IPolicyRegistryView(policyRegistry).approvedToken(token)) revert NotAuthorized();
        if (ISmartWalletView(wallet).guard() != domainGuard) revert NotAuthorized();
        ISmartWalletView(wallet).emergencyEnablePermit2ForGuard(token);
    }

    /// @notice Предлагает кошельку сменить Guard на новый (ТЗ v6.1 §32).
    function proposeWalletGuardMigration(address newGuard, address wallet)
        external
        onlyAuthorizedMigration(IGuardView(domainGuard).expectedOldGuard())
    {
        if (wallet.code.length == 0) revert ZeroAddress();
        if (ISmartWalletView(wallet).guard() != domainGuard) revert NotAuthorized();
        if (IOwnerRegistryView(ownerRegistry).isRegisteredWallet(wallet) == false) revert NotAuthorized();
        ISmartWalletView(wallet).proposeGuardMigration(newGuard);
    }

    function _apply(address oldGuard, MigrationData memory d) internal {
        address oldOwners = IGuardView(oldGuard).ownerRegistry();
        address oldPolicy = IGuardView(oldGuard).policyRegistry();

        // ---- owners ----
        address[] memory owners = IOwnerRegistryView(oldOwners).getOwners();
        if (owners.length != d.owners.length || d.isHot.length != owners.length) revert SnapshotMismatch();
        uint256 hot;
        for (uint256 i = 0; i < owners.length; i++) {
            if (owners[i] != d.owners[i]) revert SnapshotMismatch();
            if (IOwnerRegistryView(oldOwners).isOwnerHot(owners[i]) != d.isHot[i]) revert SnapshotMismatch();
            if (d.isHot[i]) hot++;
        }
        if (hot != 3 || owners.length != 5) revert SnapshotMismatch();
        IOwnerRegistryView(ownerRegistry).changeOwners(d.owners, d.isHot);

        // ---- wallets ----
        _wallets(oldOwners, d.hotWallets, true);
        _wallets(oldOwners, d.coldWallets, false);

        // ---- registries (аддитивно, как и раньше) ----
        _simple(oldPolicy, d.approvedTokens, 1);
        _simple(oldPolicy, d.approvedRouters, 2);
        _simple(oldPolicy, d.blacklistAddrs, 3);
        _simple(oldPolicy, d.tradingPlatforms, 4);

        // ---- contract policies ----
        if (d.policyContracts.length != d.policyUsdLimits.length
            || d.policyContracts.length != d.policyShareBps.length
            || d.policyContracts.length != d.policyDeadlines.length
            || d.policyContracts.length != d.policyBlocked.length) revert SnapshotMismatch();
        for (uint256 i = 0; i < d.policyContracts.length; i++) {
            address target = d.policyContracts[i];
            (bool exists, bool blocked, uint256 usdLimit, , uint256 shareBps, uint256 dl) =
                IPolicyRegistryView(oldPolicy).getContractPolicy(target);
            if (!exists) revert SnapshotMismatch();
            if (blocked != d.policyBlocked[i] || usdLimit != d.policyUsdLimits[i]
                || shareBps != d.policyShareBps[i] || dl != d.policyDeadlines[i]) revert SnapshotMismatch();
            IPolicyRegistryView(policyRegistry).setContractPolicy(
                target, d.policyBlocked[i], d.policyUsdLimits[i], d.policyShareBps[i], d.policyDeadlines[i]
            );
        }

        // ---- token risk ----
        for (uint256 i = 0; i < d.riskTokens.length; i++) {
            (bool configured, uint8 category) = IPolicyRegistryView(oldPolicy).getTokenRisk(d.riskTokens[i]);
            if (!configured || category != d.riskCategories[i]) revert SnapshotMismatch();
            IPolicyRegistryView(policyRegistry).setTokenRisk(d.riskTokens[i], d.riskCategories[i]);
        }

        // ---- token price ----
        for (uint256 i = 0; i < d.priceTokens.length; i++) {
            (bool configured, uint256 priceE18, uint8 decimals) =
                IPolicyRegistryView(oldPolicy).getTokenPrice(d.priceTokens[i]);
            if (!configured || priceE18 != d.priceE18[i] || decimals != d.priceDecimals[i]) revert SnapshotMismatch();
            IPolicyRegistryView(policyRegistry).setTokenPrice(d.priceTokens[i], d.priceE18[i], d.priceDecimals[i]);
        }

        // ---- token amount policies ----
        for (uint256 i = 0; i < d.amountTokens.length; i++) {
            (bool exists, uint256 maxAmount, uint256 shareBps) =
                IPolicyRegistryView(oldPolicy).getTokenAmountPolicy(d.amountTargets[i], d.amountTokens[i]);
            if (!exists || maxAmount != d.amountMax[i] || shareBps != d.amountShareBps[i]) revert SnapshotMismatch();
            IPolicyRegistryView(policyRegistry).setTokenAmountPolicy(
                d.amountTargets[i], d.amountTokens[i], d.amountMax[i], d.amountShareBps[i]
            );
        }

        // ---- recovery targets ----
        for (uint256 i = 0; i < d.recoveryTokens.length; i++) {
            (bool exists, address recipient) =
                IPolicyRegistryView(oldPolicy).getRecoveryTarget(d.recoveryWallets[i], d.recoveryTokens[i]);
            if (!exists || recipient != d.recoveryRecipients[i]) revert SnapshotMismatch();
            IPolicyRegistryView(policyRegistry).setRecoveryTarget(
                d.recoveryWallets[i], d.recoveryTokens[i], d.recoveryRecipients[i]
            );
        }

        if (d.defaultTransferShareBps != 0) {
            IPolicyRegistryView(policyRegistry).setDefaultTransferShareBps(d.defaultTransferShareBps);
        }

        // ---- subscription + configuration ----
        ISubscriptionsView(subscriptions).claimSubscription(d.subscriptionPlan, d.subscriptionExpiresAt);
        ISubscriptionsView(subscriptions).claimConfiguration(
            d.treasury, d.appVersionHash, d.p2pAdmin, d.p2pDAO, d.p2pTimeout,
            new uint8[](0), new address[](0), new uint256[](0), new uint64[](0), new bool[](0)
        );

        // ---- Guard-локальное состояние через сам Guard ----
        IGuardView(domainGuard).claimStrictKey(d.strictKey);
        if (d.migrationEmergencyKey != address(0)) {
            IGuardView(domainGuard).claimMigrationEmergencyKey(d.migrationEmergencyKey);
        }
        IGuardView(domainGuard).markInitialized();
    }

    function _wallets(address oldOwners, address[] memory wallets, bool isHot) internal {
        for (uint256 i = 0; i < wallets.length; i++) {
            address w = wallets[i];
            if (!IOwnerRegistryView(oldOwners).isRegisteredWallet(w)) revert SnapshotMismatch();
            if (IOwnerRegistryView(oldOwners).isHotWallet(w) != isHot) revert SnapshotMismatch();
            for (uint256 j = 0; j < i; j++) {
                if (wallets[j] == w) revert SnapshotMismatch();
            }
            IOwnerRegistryView(ownerRegistry).addWallet(w, isHot);
        }
    }

    function _simple(address oldPolicy, address[] memory items, uint8 kind) internal {
        for (uint256 i = 0; i < items.length; i++) {
            address a = items[i];
            if (a == address(0)) revert ZeroAddress();

                : kind == 3 ? IPolicyRegistryView(oldPolicy).blacklist(a)

            if (kind == 1) IPolicyRegistryView(policyRegistry).addToken(a);
            else if (kind == 2) IPolicyRegistryView(policyRegistry).addRouter(a);
            else if (kind == 3) IPolicyRegistryView(policyRegistry).addBlacklist(a);
            else IPolicyRegistryView(policyRegistry).addTradingPlatform(a);
        }
    }

pragma solidity 0.8.30;

import { GuardOps } from "./GuardOps.sol";
import { IGuardView, IOwnerRegistryView, IMigrationHubView } from "./GuardInterfaces.sol";

/* =========================================================================
   SmartWalletGuard v6.1.0 — Migration Hub
   =========================================================================
   ЕДИНСТВЕННЫЙ ИСТОЧНИК ИСТИНЫ по состоянию миграции (ТЗ v6.1 §28-§34).

   Guard больше не хранит `migratedOut` / `migrationAccepted` / `migratedTo` и
   не имеет `markMigratedOut` / `acceptMigrationIn`. Вместо этого Guard
   спрашивает Hub:

     migrationStateOf(guard)          состояние миграции
     finalizedOut(guard)              Guard уже мигрировал наружу
     acceptedFrom(newGuard, oldGuard) новый Guard принял эту миграцию
     authorizedMigration(newGuard)    можно ли применять снапшот

   Guard читает это в модификаторе `notMigrated`, поэтому состояние миграции
   не может быть подделано ни самим Guard-ом, ни владельцами.

   Применение снапшота выполняет SmartWalletGuardMigrationModule: Hub только
   ведёт состояние, таймлок и отмены, а затем вызывает `applySnapshot`.
   Adapter policies не мигрируют — адаптеров в v6.1 нет (§34).
   ========================================================================= */

interface IMigrationTargetModule {
    function applySnapshot(address oldGuard, bytes32 migrationDataHash, bytes calldata migrationData) external;
}

contract SmartWalletMigrationHub {

    string public constant VERSION = "6.1.0";

    enum MigrationState { NONE, PROPOSED, READY, FINALIZED, CANCELLED }

    uint256 public constant MIGRATION_DELAY = 48 hours;
    uint256 public constant MAX_MIGRATION_CANCELS = 3;

    struct Migration {
        address oldGuard;
        address newGuard;
        bytes32 migrationDataHash;
        uint256 proposedAt;
        uint256 executableAt;
        MigrationState state;
        bool emergency;
    }

    address public immutable mainWallet;
    address public immutable permit2;
    bytes32 public immutable DOMAIN_SEPARATOR;

    /// @notice Hub, обслуживающий конкретный Guard (может быть только один).
    mapping(address => address) public guardHub;
    mapping(address => uint256) public currentMigrationId;
    mapping(uint256 => Migration) public migrations;
    mapping(uint256 => bool) private _applied;

    /// @notice mainWallet + newGuard => количество отмен (§39).
    mapping(address => mapping(address => uint256)) public migrationCancelCount;

    /// @notice newGuard => oldGuard, от которого принята финализированная миграция.
    mapping(address => address) public acceptedFrom;
    mapping(address => bool) public finalizedOut;

    uint256 public totalMigrations;
    bool public locked;

    event MigrationProposed(
        uint256 indexed migrationId, address indexed oldGuard, address indexed newGuard,
        bytes32 migrationDataHash, uint256 executableAt, bool emergency
    );
    event MigrationCancelled(uint256 indexed migrationId, address indexed oldGuard, address indexed newGuard, uint256 cancelCount);
    event MigrationFinalized(uint256 indexed migrationId, address indexed oldGuard, address indexed newGuard);
    event MigrationStateChanged(uint256 indexed migrationId, MigrationState state);
    event GuardHubUpdated(address indexed guard, address indexed hub);

    error NotAuthorized();
    error BadGuard();
    error BadNewGuard();
    error NoMigration();
    error WrongState();
    error TimelockActive();
    error DeadlineExpired();
    error HashMismatch();
    error MaxCancelsReached();
    error CancelsNotReached();
    error EmergencyKeyNotSet();
    error InvalidEmergencySignature();
    error ZeroAddress();
    error NotContract();
    error Reentrant();

    constructor(address mainWallet_, address permit2_) {
        if (mainWallet_ == address(0)) revert ZeroAddress();
        if (permit2_ == address(0) || permit2_.code.length == 0) revert NotContract();
        mainWallet = mainWallet_;
        permit2 = permit2_;
        DOMAIN_SEPARATOR = GuardOps.domainSeparator(block.chainid, address(this));
    }

    modifier nonReentrant() {
        if (locked) revert Reentrant();
        locked = true;
        _;
        locked = false;
    }

    // =========================================================================
    // Состояние — то, что читает Guard
    // =========================================================================

    function migrationStateOf(address guard_) external view returns (uint8) {
        uint256 id = currentMigrationId[guard_];
        if (id == 0) return uint8(MigrationState.NONE);
        Migration memory m = migrations[id];
        if (m.state == MigrationState.PROPOSED && block.timestamp >= m.executableAt) {
            return uint8(MigrationState.READY);
        }
        return uint8(m.state);
    }

    function isFinalizedOut(address guard_) external view returns (bool) { return finalizedOut[guard_]; }

    /// @notice Проверка привязки: Guard ссылается на этот Hub.
    function isBoundTo(address guard_) external view returns (bool) {
        if (guard_ == address(0) || guard_.code.length == 0) return false;
        return IGuardView(guard_).migrationHub() == address(this);
    }

    function authorizedMigration(address newGuard) external view returns (bool) {
        if (acceptedFrom[newGuard] == address(0)) return false;
        uint256 id = currentMigrationId[newGuard];
        return id != 0 && migrations[id].state == MigrationState.FINALIZED;
    }

    /// @notice Взаимная привязка Hub-а и Guard-а. Достаточно, чтобы Guard уже
    ///         ссылался на этот Hub (`migrationHub()`), тогда вызов может
    ///         сделать кто угодно — состояние от этого не меняется, кроме
    ///         фиксации уже существующей связи.
    function bindGuard(address guard_) external {
        if (guard_ == address(0) || guard_.code.length == 0) revert NotContract();
        if (IGuardView(guard_).migrationHub() != address(this)) revert NotAuthorized();
        if (guardHub[guard_] != address(0)) return;
        guardHub[guard_] = address(this);
        emit GuardHubUpdated(guard_, address(this));
    }

    // =========================================================================
    // Предложение миграции — 3/5 + Cold
    // =========================================================================

    /// @param oldGuard Guard, который мигрирует наружу
    /// @param newGuard целевой Guard (`expectedOldGuard` уже выставлен)
    function proposeMigration(
        address oldGuard,
        address newGuard,
        bytes32 migrationDataHash,
        uint256 nonce,
        uint256 deadline,
        bytes[] calldata signatures
    ) external returns (uint256 migrationId) {
        _checkOld(oldGuard);
        _checkNew(oldGuard, newGuard);
        if (migrationCancelCount[mainWallet][newGuard] >= MAX_MIGRATION_CANCELS) revert MaxCancelsReached();

        uint256 executableAt = block.timestamp + MIGRATION_DELAY;
        bytes32 dgst = _proposalDigest(oldGuard, newGuard, migrationDataHash, nonce, executableAt, deadline, false);
        _consumeCritical(oldGuard, dgst, nonce, deadline, signatures);
        migrationId = _create(oldGuard, newGuard, migrationDataHash, executableAt, false);
    }

    /// @notice Emergency-путь доступен только после MAX_MIGRATION_CANCELS отмен
    ///         на этот же newGuard (§39/§40) и требует подписи
    ///         migrationEmergencyKey + 3/5 с Cold.
    /// @dev `executeAfter` входит в digest как фиксированное значение и НЕ
    ///      берётся из `block.timestamp` после подписи, иначе подпись была бы
    ///      валидна ровно один блок (дефект v5.2.1/v6.0.0).
    function proposeMigrationWithEmergency(
        address oldGuard,
        address newGuard,
        bytes32 migrationDataHash,
        uint256 nonce,
        uint256 deadline,
        bytes calldata emergencySignature,
        bytes[] calldata signatures
    ) external returns (uint256 migrationId) {
        _checkOld(oldGuard);
        _checkNew(oldGuard, newGuard);
        if (migrationCancelCount[mainWallet][newGuard] < MAX_MIGRATION_CANCELS) revert CancelsNotReached();

        address key = IGuardView(oldGuard).migrationEmergencyKey();
        if (key == address(0)) revert EmergencyKeyNotSet();

        uint256 executableAt = block.timestamp;
        bytes32 dgst = _proposalDigest(oldGuard, newGuard, migrationDataHash, nonce, executableAt, deadline, true);
        if (GuardOps.recover(dgst, emergencySignature) != key) revert InvalidEmergencySignature();
        _consumeCritical(oldGuard, dgst, nonce, deadline, signatures);

        migrationId = _create(oldGuard, newGuard, migrationDataHash, executableAt, true);
    }

    function cancelMigration(uint256 migrationId, uint256 nonce, uint256 deadline, bytes[] calldata signatures)
        external
    {
        Migration storage m = migrations[migrationId];
        if (m.oldGuard == address(0)) revert NoMigration();
        if (m.state != MigrationState.PROPOSED) revert WrongState();
        if (block.timestamp >= m.executableAt) revert TimelockActive();

        bytes32 dgst = GuardOps.digestOf(
            DOMAIN_SEPARATOR,
            GuardOps.cancelMigrationHash(mainWallet, m.newGuard, nonce, deadline)
        );
        _consumeCritical(m.oldGuard, dgst, nonce, deadline, signatures);

        uint256 newCount = migrationCancelCount[mainWallet][m.newGuard] + 1;
        migrationCancelCount[mainWallet][m.newGuard] = newCount;
        m.state = MigrationState.CANCELLED;
        emit MigrationCancelled(migrationId, m.oldGuard, m.newGuard, newCount);
        emit MigrationStateChanged(migrationId, MigrationState.CANCELLED);
    }

    // =========================================================================
    // Финализация
    // =========================================================================

    /// @notice Финализирует миграцию и применяет снапшот на новом Guard-е через
    ///         его migration module. Атомарно: при revert состояние не
    ///         фиксируется (ТЗ §75 v5.1.4).
    function finalizeMigration(uint256 migrationId, bytes calldata migrationData) external nonReentrant {
        Migration storage m = migrations[migrationId];
        if (m.oldGuard == address(0)) revert NoMigration();
        if (m.state != MigrationState.PROPOSED && m.state != MigrationState.READY) revert WrongState();
        if (block.timestamp < m.executableAt) revert TimelockActive();
        if (keccak256(migrationData) != m.migrationDataHash) revert HashMismatch();
        if (_applied[migrationId]) revert WrongState();

        address oldGuard = m.oldGuard;
        address newGuard = m.newGuard;

        // Порядок важен: сначала фиксируем состояние, потому что модуль
        // проверяет `authorizedMigration(newGuard)` и `acceptedFrom`.
        m.state = MigrationState.FINALIZED;
        finalizedOut[oldGuard] = true;
        acceptedFrom[newGuard] = oldGuard;
        currentMigrationId[newGuard] = migrationId;
        _applied[migrationId] = true;
        emit MigrationStateChanged(migrationId, MigrationState.FINALIZED);

        address module = IGuardView(newGuard).migrationModule();
        if (module == address(0) || module.code.length == 0) revert NotContract();
        IMigrationTargetModule(module).applySnapshot(oldGuard, m.migrationDataHash, migrationData);

        emit MigrationFinalized(migrationId, oldGuard, newGuard);
    }

    // =========================================================================
    // Внутреннее
    // =========================================================================

    function _checkOld(address oldGuard) internal view {
        if (oldGuard == address(0) || oldGuard.code.length == 0) revert BadGuard();
        if (IGuardView(oldGuard).mainWallet() != mainWallet) revert NotAuthorized();
        if (IGuardView(oldGuard).permit2() != permit2) revert NotAuthorized();
        if (finalizedOut[oldGuard]) revert WrongState();
        if (guardHub[oldGuard] != address(this)) revert NotAuthorized();
        uint256 id = currentMigrationId[oldGuard];
        if (id != 0) {
            MigrationState s = migrations[id].state;
            if (s == MigrationState.PROPOSED || s == MigrationState.READY) revert WrongState();
        }
    }

    function _checkNew(address oldGuard, address newGuard) internal view {
        if (newGuard == address(0) || newGuard.code.length == 0) revert BadNewGuard();
        if (newGuard == oldGuard) revert BadNewGuard();
        if (IGuardView(newGuard).mainWallet() != mainWallet) revert NotAuthorized();
        if (IGuardView(newGuard).permit2() != permit2) revert NotAuthorized();
        if (IGuardView(newGuard).expectedOldGuard() != oldGuard) revert BadNewGuard();
        if (acceptedFrom[newGuard] != address(0)) revert WrongState();
        if (guardHub[newGuard] != address(0) && guardHub[newGuard] != address(this)) revert BadNewGuard();
    }

    function _create(
        address oldGuard, address newGuard, bytes32 migrationDataHash, uint256 executableAt, bool emergency
    ) internal returns (uint256 id) {
        id = ++totalMigrations;
        migrations[id] = Migration(
            oldGuard, newGuard, migrationDataHash, block.timestamp, executableAt, MigrationState.PROPOSED, emergency
        );
        currentMigrationId[oldGuard] = id;
        guardHub[newGuard] = address(this);
        emit MigrationProposed(id, oldGuard, newGuard, migrationDataHash, executableAt, emergency);
    }

    function _proposalDigest(
        address oldGuard, address newGuard, bytes32 migrationDataHash,
        uint256 nonce, uint256 executableAt, uint256 deadline, bool emergency
    ) internal view returns (bytes32) {
        return GuardOps.digestOf(
            DOMAIN_SEPARATOR,
            GuardOps.migrationHash(mainWallet, newGuard, migrationDataHash, nonce, executableAt, deadline, emergency)
        );
    }

    function _consumeCritical(
        address guard_, bytes32 dgst, uint256 nonce, uint256 deadline, bytes[] calldata signatures
    ) internal {
        if (block.timestamp > deadline) revert DeadlineExpired();
        IOwnerRegistryView(IGuardView(guard_).ownerRegistry()).requireSignatures(dgst, signatures, true);
        if (!IGuardView(guard_).consumeGovernanceNonce(nonce)) revert NotAuthorized();
    }
}

    function _twoHot(bytes32 digest) internal view returns (bytes[] memory sigs) {

                mainWallet, uint8(1), uint8(1), bytes32(bytes20(w)), bytes32(0),
                isHot ? uint256(1) : uint256(0), uint256(0), nonce, deadline
            ))
        ));
    }

"""Cross-check that every interface call made by a contract exists in the
target contract's compiled ABI. Guards against signature drift between
modules after refactoring."""
import json
import os
import re
import sys

W = r"C:\Users\Виталя\Documents\deepseek-harness\default-workspace"
BUILD = os.path.join(W, "build")
CONTRACTS = os.path.join(W, "contracts")


def load_abi(name):
    with open(os.path.join(BUILD, name + ".abi.json"), encoding="utf-8") as f:
        return json.load(f)


def abi_index(abi):
    """selector-name -> (n_inputs, input_types)"""
    idx = {}
    for item in abi:
        if item.get("type") != "function":
            continue
        idx[item["name"]] = [i["type"] for i in item.get("inputs", [])]
    return idx


INTERFACE_TARGET = {
    "GuardOps": None,
    "ISubscriptionsView": "SmartWalletGuardSubscriptions",
    "IPolicyRegistryView": "SmartWalletPolicyRegistry",
    "IOwnerRegistryView": "SmartWalletGuardOwnerRegistry",
    "ISmartWalletView": None,
    "IPermit2View": None,
    "ISwapAdapterView": None,
    "IERC20View": None,
    "IGuardView": "SmartWalletGuard",
}

abis = {
    "SmartWalletGuard": abi_index(load_abi("SmartWalletGuard")),
    "SmartWalletGuardSubscriptions": abi_index(load_abi("SmartWalletGuardSubscriptions")),
    "SmartWalletPolicyRegistry": abi_index(load_abi("SmartWalletPolicyRegistry")),
    "SmartWalletGuardOwnerRegistry": abi_index(load_abi("SmartWalletGuardOwnerRegistry")),
}

CALL_RE = re.compile(r"(I\w+View|GuardOps)\([^)]*\)\.(\w+)\(")
problems = 0
checked = 0

for fname in os.listdir(CONTRACTS):
    if not fname.endswith(".sol"):
        continue
    with open(os.path.join(CONTRACTS, fname), encoding="utf-8") as f:
        src = f.read()
    for m in CALL_RE.finditer(src):
        iface, fn = m.group(1), m.group(2)
        target = INTERFACE_TARGET.get(iface)
        if target is None:
            continue
        checked += 1
        if fn not in abis[target]:
            print("MISSING  %-28s -> %s.%s" % (fname, target, fn))
            problems += 1

print("interface calls checked:", checked, "problems:", problems)
sys.exit(1 if problems else 0)

const https = require('https');
const fs = require('fs');

const url = process.argv[2];
const out = process.argv[3];

function get(u, redirects) {
  if (redirects > 6) throw new Error('too many redirects');
  https.get(u, { headers: { 'user-agent': 'node' } }, (res) => {
    if (res.statusCode >= 300 && res.statusCode < 400 && res.headers.location) {
      res.resume();
      return get(res.headers.location, redirects + 1);
    }
    if (res.statusCode !== 200) {
      fs.writeFileSync(out + '.err', 'HTTP ' + res.statusCode);
      process.exit(2);
    }
    const chunks = [];
    res.on('data', (d) => chunks.push(d));
    res.on('end', () => {
      const buf = Buffer.concat(chunks);
      fs.writeFileSync(out, buf);
      console.log('wrote', buf.length, 'bytes');
    });
  }).on('error', (e) => {
    fs.writeFileSync(out + '.err', String(e && e.message));
    process.exit(3);
  });
}

get(url, 0);

# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## SmartWalletGuard v5.1.4
Тип: on-chain security / policy / authorization controller для non-custodial Smart Wallet
Язык: Solidity ^0.8.20
Основной стандарт: EVM-compatible networks
Ключевые зависимости: Uniswap Permit2, SmartHotWallet, SmartColdWallet, adapters

# 68. Migration acceptance

# 69. Wallet migration
Каждый Smart Wallet должен мигрироваться отдельно.

# 70. Wallet migration validation
Перед accept:
wallet.guard() == expectedOldGuard
После:
wallet.guard() == address(this)
Если не получилось:
revert
# 71. Permit2 migration
При смене Guard старый wallet должен:
revoke Permit2 allowance for old Guard
revoke ERC20 -> Permit2 allowance if required
change guard
После migration новый Guard должен повторно enable Permit2 для нужных tokens.
# 72. Adapter migration
UniswapV2Adapter должен иметь immutable:

address immutable router;
Старый adapter нельзя просто переключить на новый Guard.
Поэтому при migration:
old adapters remain tied to old Guard
new adapters deployed for new Guard
Нельзя делать guard mutable только ради migration.
# 73. Migration state flags
Guard должен иметь:

# 74. Post-migration behavior

Он становится историческим source Guard.
New Guard становится active authority.

# 116. Critical security properties
Контракт считается корректным только если гарантируются следующие invariants:
### Invariant 1
Ни один unregistered wallet не может использовать Guard.
### Invariant 2
Ни один unapproved token не может использоваться в обычном transfer/swap/subscription payment.
### Invariant 3
Ни один unapproved router не может использоваться.
### Invariant 4
Ни один unapproved adapter не может использоваться.
### Invariant 5
Blacklist имеет приоритет над whitelist.
### Invariant 6
Удаление из registry немедленно прекращает новые операции.
### Invariant 7
Subscription не может заблокировать emergency recovery.
### Invariant 8
Emergency Sweep не позволяет caller выбрать произвольный recipient.
### Invariant 9
Recovery recipient повторно проверяется на blacklist.
### Invariant 10
Обычная операция требует правильного signature threshold.
### Invariant 11
Critical operation требует Cold Owner.
### Invariant 12
Nonce нельзя использовать повторно.
### Invariant 13
Expired deadline запрещает execution.
### Invariant 14
Expired Permit2 allowance запрещает execution.
### Invariant 15
Old Guard после migration не может продолжать обычное управление.
### Invariant 16
Migration не может успешно завершиться без 48h delay, кроме предусмотренного emergency migration path.
### Invariant 17
Emergency migration не может быть вызвана до достижения cancellation threshold.
### Invariant 18
Backend не получает custody.
### Invariant 19
Guard не содержит пользовательские средства.
### Invariant 20
Ни одна функция не должна предоставлять arbitrary call/delegatecall.

# 124. Главный security принцип
Вся система должна строиться вокруг следующего правила:
WALLET DOES NOT TRUST THE DESTINATION.
GUARD DECIDES WHAT IS ALLOWED.
Wallet не должен иметь возможность самостоятельно отправить средства на произвольный адрес через универсальный executor.
Guard не должен иметь возможность произвольно выполнять calldata.
Backend не должен иметь custody.
Subscription не должна управлять custody.
Permit2 не должен превращаться в unrestricted spending authority.
Каждая операция должна проходить через:
Wallet
→ Guard
→ Signature validation
→ Registry validation
→ Blacklist validation
→ Policy validation
→ Limit validation
→ Permit2 / Adapter
→ Execution
А emergency flow должен быть отдельным узким исключением:
Wallet paused
→ Stored recovery target
→ 2/3 Hot
→ Emergency Sweep
